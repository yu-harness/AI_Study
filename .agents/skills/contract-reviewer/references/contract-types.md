# 合同类型专项审查模板

本文档定义了四种合同类型的专项审查规则。Claude 在审查合同时，根据合同类型匹配 `<type name="...">` 标签内的检查点，与通用规则同步执行。

格式说明：
- 每个 `<type>` 块代表一种合同类型
- `<checkpoint>` 代表一个专项审查项，包含：关键词、检查内容、风险定级标准、输出模板
- 如果合同不属于任何已定义类型，则仅使用通用审查规则

---

<type name="买卖合同">

## 买卖合同专项审查

适用于：货物买卖、设备采购、商品购销等以"标的物所有权转移"为核心的合同。

### 检查点 1：质量标准与验收

<checkpoint id="purchase-quality">
- **审查目标**：是否明确约定质量标准和验收程序
- **关键词**：质量、标准、国标、验收、检验、合格、不合格、瑕疵
- **判断标准**：
  - 明确：引用具体标准编号（如 GB/T xxxx），约定检验期限和异议提出方式
  - 模糊：仅说"符合质量要求"但无具体标准
  - 缺失：完全未提及质量标准
- **风险定级**：
  | 情况 | 等级 |
  |------|------|
  | 质量标准完全缺失 | 🔴 高风险 |
  | 标准模糊（无具体引用） | 🟡 中风险 |
  | 标准明确但检验期限过短（委托方为买方时） | 🟡 中风险 |
  | 标准明确且合理 | ✅ 无风险 |
- **输出模板**：
  ```
  [质量标准缺失/模糊] 第X条约定"原文"
  风险：(说明具体风险)
  建议：(1)引用具体质量标准；(2)约定检验期限；(3)明确异议提出方式
  ```
</checkpoint>

### 检查点 2：交付与所有权转移

<checkpoint id="purchase-delivery">
- **审查目标**：交付方式、时间、地点是否明确，所有权和风险转移时点是否清晰
- **关键词**：交付、交货、运输、签收、所有权、风险转移、毁损、灭失
- **判断标准**：
  - 明确：约定交货地点、运输方式、签收即视为交付、风险转移时点
  - 模糊：仅有"交付"二字但无具体细节
  - 缺失：未约定交付条款
- **风险定级**：
  | 情况 | 等级 |
  |------|------|
  | 交付条款完全缺失 | 🔴 高风险 |
  | 未约定风险转移时点 | 🟡 中风险 |
  | 交付方式/地点模糊 | 🟡 中风险 |
- **输出模板**：
  ```
  [交付约定不明确] 第X条约定"原文"
  风险：(运输途中毁损由谁承担不明)
  建议：明确交货地点和运输方式，约定风险转移时点
  ```
</checkpoint>

### 检查点 3：瑕疵担保与售后服务

<checkpoint id="purchase-warranty">
- **审查目标**：是否约定质量保证期和售后责任
- **关键词**：质保、保修、售后、退换、维修、保质期
- **判断标准**：
  - 完善：有质保期限、保修范围、响应时间
  - 简单：提及质保但无具体范围
  - 缺失：无任何质保约定
- **风险定级**：
  | 情况 | 等级 |
  |------|------|
  | 完全无质保条款（委托方为买方时） | 🟡 中风险 |
  | 质保期限过短 | ℹ️ 提示 |
  | 质保范围不清晰 | ℹ️ 提示 |
- **输出模板**：
  ```
  [缺少质保条款] 合同未约定质量保证期
  风险：买方在接收货物后如发现隐蔽瑕疵，缺少追责依据
  建议：增加质保条款，明确质保期限、保修范围和响应时间
  ```
</checkpoint>

### 检查点 4：不可抗力范围

<checkpoint id="purchase-force-majeure">
- **审查目标**：不可抗力条款是否合理，是否被对方滥用规避交货义务
- **关键词**：不可抗力、免责、自然灾害、疫情、政府行为
- **判断标准**：
  - 合理：列举典型不可抗力事件 + 通知义务 + 减损义务
  - 过于宽泛：将"市场行情变化"、"供应链波动"等商业风险纳入不可抗力
  - 缺失：未约定（可接受，法律规定兜底）
- **风险定级**：
  | 情况 | 等级 |
  |------|------|
  | 不可抗力范围过于宽泛（对方可轻易免责） | 🟡 中风险 |
  | 无通知义务和减损义务 | ℹ️ 提示 |
- **输出模板**：
  ```
  [不可抗力范围过宽] 第X条将商业风险纳入不可抗力
  风险：对方可能滥用不可抗力条款规避交货义务
  建议：将商业风险排除在不可抗力范围之外，增加通知和减损义务
  ```
</checkpoint>

</type>

<type name="租赁合同">

## 租赁合同专项审查

适用于：房屋租赁、设备租赁、场地租赁等以"使用权的有偿转移"为核心的合同。

### 检查点 1：维修责任划分

<checkpoint id="lease-repair">
- **审查目标**：出租方和承租方的维修责任是否明确划分
- **关键词**：维修、修缮、损坏、自然损耗、人为、大修、日常维护
- **判断标准**：
  - 明确：区分大修（出租方承担）和日常维护（承租方承担）
  - 模糊：仅说"维修由双方协商"
  - 缺失/不合理：将全部维修责任推给承租方
- **风险定级**：
  | 情况 | 等级 |
  |------|------|
  | 全部维修责任由承租方承担（委托方为承租方时） | 🔴 高风险 |
  | 维修责任划分不明确 | 🟡 中风险 |
  | 仅约定承租方维修义务 | 🟡 中风险 |
- **法规参考**：《民法典》第712条——出租人应当履行租赁物的维修义务
- **输出模板**：
  ```
  [维修责任不公/不明] 第X条约定"原文"
  风险：(引用民法典712条)
  建议：明确大修由出租方负责，日常维护由承租方负责，约定报修响应时间
  ```
</checkpoint>

### 检查点 2：转租限制

<checkpoint id="lease-sublet">
- **审查目标**：是否约定转租相关条款
- **关键词**：转租、分租、转让、第三方使用
- **判断标准**：
  - 明确：是否允许转租、转租需经出租方书面同意
  - 缺失：未提及转租（缺乏违约后果）
- **风险定级**：
  | 情况 | 等级 |
  |------|------|
  | 未约定转租违约后果 | ℹ️ 提示 |
- **输出模板**：
  ```
  [转租条款缺失] 合同未约定转租限制
  建议：增加"未经出租方书面同意不得转租；擅自转租的，出租方有权解除合同"
  ```
</checkpoint>

### 检查点 3：押金退还条件

<checkpoint id="lease-deposit">
- **审查目标**：押金退还条件是否明确、合理
- **关键词**：押金、保证金、退还、扣除、退租
- **判断标准**：
  - 明确：约定退还时间、扣除情形、争议解决
  - 模糊：仅说"押金在退租时退还"
  - 不公：未约定退还时间，或出租方可无限期扣留
- **风险定级**：
  | 情况 | 等级 |
  |------|------|
  | 未约定押金退还时间（委托方为承租方时） | 🟡 中风险 |
  | 押金扣除条件过于模糊 | 🟡 中风险 |
  | 押金金额过高（超2-3个月租金） | ℹ️ 提示 |
- **输出模板**：
  ```
  [押金退还条件不明确] 第X条约定"原文"
  风险：退租时出租方可能拖延或拒绝退还押金
  建议：明确退还时间（7个工作日内）、可扣除情形、扣除需提供票据
  ```
</checkpoint>

### 检查点 4：续租与优先权

<checkpoint id="lease-renewal">
- **审查目标**：是否约定续租条件、优先购买权
- **关键词**：续租、续约、优先、购买、出售、到期
- **判断标准**：
  - 完善：约定续租通知期限、租金调整机制
  - 缺失：未约定
- **风险定级**：
  | 情况 | 等级 |
  |------|------|
  | 合同到期续租条件不明 | ℹ️ 提示 |
- **输出模板**：
  ```
  [续租条款建议补充] 合同未约定续租条件
  建议：增加续租通知期限和租金调整机制
  ```
</checkpoint>

</type>

<type name="服务合同">

## 服务合同专项审查

适用于：技术开发、咨询服务、设计外包、运维服务等以"劳务或智力成果交付"为核心的合同。

### 检查点 1：服务标准与 SLA

<checkpoint id="service-sla">
- **审查目标**：服务内容、交付标准、响应时效是否明确
- **关键词**：SLA、服务等级、响应时间、可用性、故障、维护、服务内容
- **判断标准**：
  - 明确：有具体的服务范围、交付物清单、验收标准、响应时效
  - 模糊：仅有笼统的服务描述
  - 缺失：完全未定义服务标准
- **风险定级**：
  | 情况 | 等级 |
  |------|------|
  | 服务内容和交付标准完全缺失 | 🔴 高风险 |
  | 服务内容有描述但无验收标准 | 🟡 中风险 |
  | 无SLA或响应时效约定 | 🟡 中风险 |
- **输出模板**：
  ```
  [服务标准模糊] 第X条约定"原文"
  风险：对方可能以低质量服务交付后主张已完成履约
  建议：(1)以附件列出服务范围清单；(2)约定验收标准；(3)增加SLA条款
  ```
</checkpoint>

### 检查点 2：知识产权归属

<checkpoint id="service-ip">
- **审查目标**：项目成果的知识产权归谁所有，背景IP是否明确
- **关键词**：知识产权、著作权、专利、源代码、版权、IP、归属
- **判断标准**：
  - 明确：区分背景IP（各方保留）和前景IP（成果归属），约定使用许可
  - 模糊：仅说"知识产权归委托方"但未区分背景IP
  - 缺失：未约定（默认归创作方，委托方可能仅有使用权）
- **风险定级**：
  | 情况 | 等级 |
  |------|------|
  | 未约定知识产权归属（委托方为出资方时） | 🔴 高风险 |
  | 归属明确但未处理背景IP授权 | 🟡 中风险 |
  | 归属条款对委托方不利 | 🔴 高风险 |
- **法规参考**：《著作权法》第19条——委托创作合同未约定版权归属的，著作权属于受托人
- **输出模板**：
  ```
  [知识产权归属缺失/不利] 第X条约定"原文"
  风险：根据《著作权法》第19条，未约定则著作权归受托人
  建议：明确成果知识产权归委托方，服务方背景IP授予永久使用许可
  ```
</checkpoint>

### 检查点 3：竞业限制

<checkpoint id="service-noncompete">
- **审查目标**：是否限制服务方同时为竞争对手提供服务
- **关键词**：竞业、竞争、排他、独家、禁止
- **判断标准**：
  - 有约定：明确竞业范围和期限
  - 缺失：未约定
- **风险定级**：
  | 情况 | 等级 |
  |------|------|
  | 涉及核心技术但未约定竞业限制 | 🟡 中风险 |
  | 一般性服务未约定竞业 | ℹ️ 提示 |
- **输出模板**：
  ```
  [缺少竞业限制] 合同未约定竞业限制条款
  风险：服务方可能同时为竞争对手提供同类服务
  建议：增加竞业限制条款，明确范围和期限
  ```
</checkpoint>

### 检查点 4：分包限制

<checkpoint id="service-subcontract">
- **审查目标**：是否允许服务方将工作分包给第三方
- **关键词**：分包、转包、第三方、外包、委托
- **判断标准**：
  - 明确：是否允许分包、需经委托方书面同意
  - 缺失：未约定
- **风险定级**：
  | 情况 | 等级 |
  |------|------|
  | 核心工作可任意分包（委托方为甲方时） | 🟡 中风险 |
  | 未约定分包限制 | ℹ️ 提示 |
- **输出模板**：
  ```
  [分包缺少限制] 合同未限制服务方分包
  风险：核心工作可能被转包给不了解的第三方
  建议：增加"未经书面同意不得将主要义务分包或转包"
  ```
</checkpoint>

</type>

<type name="劳动合同">

## 劳动合同专项审查

适用于：劳动合同、聘用合同、劳务派遣合同等以"建立劳动关系"为核心的合同。

### 检查点 1：试用期合法性

<checkpoint id="labor-probation">
- **审查目标**：试用期长度是否符合法律规定
- **关键词**：试用期、转正、录用条件
- **判断标准**：
  - 合法：试用期 ≤ 法定上限
  - 违规：超过法定上限或重复约定
- **法规参考**：《劳动合同法》第19条
- **风险定级**：
  | 情况 | 等级 |
  |------|------|
  | 试用期明显超过法定上限 | 🔴 高风险 |
  | 仅约定试用期未约定合同期限 | 🟡 中风险 |
  | 试用期工资低于转正工资80% | 🟡 中风险 |
- **输出模板**：
  ```
  [试用期违规] 第X条约定试用期"原文"
  风险：超出《劳动合同法》第19条法定上限
  建议：调整为不超过X个月，试用期工资不低于转正工资80%
  ```
</checkpoint>

### 检查点 2：竞业限制补偿金

<checkpoint id="labor-noncompete">
- **审查目标**：竞业限制是否附带经济补偿
- **关键词**：竞业限制、竞业禁止、补偿金、补偿
- **判断标准**：
  - 完善：竞业限制 + 补偿金（≥ 月均工资30%）
  - 缺失补偿：有竞业限制但无补偿金
  - 补偿过低：低于法定标准
- **法规参考**：《劳动合同法》第23条 + 最高法司法解释
- **风险定级**：
  | 情况 | 等级 |
  |------|------|
  | 有竞业限制但未约定补偿金（委托方为劳动者时） | 🔴 高风险 |
  | 补偿金低于法定最低标准 | 🟡 中风险 |
  | 竞业限制范围过宽 | 🟡 中风险 |
- **输出模板**：
  ```
  [竞业限制缺少补偿金] 第X条约定竞业限制但无经济补偿
  风险：根据《劳动合同法》第23条，未约定补偿金的竞业限制可能不生效
  建议：补充约定按月支付的竞业限制补偿金
  ```
</checkpoint>

### 检查点 3：社保与公积金

<checkpoint id="labor-social-security">
- **审查目标**：是否明确约定社保和公积金缴纳
- **关键词**：社保、社会保险、五险一金、公积金、住房公积金
- **判断标准**：
  - 明确：约定依法缴纳
  - 异常：出现"自愿放弃社保"、"社保折现"、"不缴公积金"
  - 缺失：未提及
- **风险定级**：
  | 情况 | 等级 |
  |------|------|
  | 含"自愿放弃社保"或"社保折现"条款 | 🔴 高风险（违法条款） |
  | 含"不缴公积金"约定 | 🔴 高风险 |
  | 未约定社保缴纳基数 | ℹ️ 提示 |
- **输出模板**：
  ```
  [违法条款-社保] 第X条约定"原文"
  风险：根据《社会保险法》，社保缴纳是法定义务，不得通过协议免除
  建议：删除该条款，改为依法缴纳
  ```
</checkpoint>

### 检查点 4：单方解除条件

<checkpoint id="labor-termination">
- **审查目标**：合同解除条款是否符合法律规定
- **关键词**：解除、终止、辞退、开除、辞职、离职、通知期
- **判断标准**：
  - 合法：符合《劳动合同法》第39-41条
  - 违规：无条件辞退、限制辞职权的违约金
- **风险定级**：
  | 情况 | 等级 |
  |------|------|
  | 约定"甲方可无条件解除"（委托方为劳动者时） | 🔴 高风险 |
  | 约定违约金限制劳动者辞职 | 🔴 高风险 |
  | 离职通知期超出法定30日 | 🟡 中风险 |
- **输出模板**：
  ```
  [违法解除条款] 第X条约定"原文"
  风险：违反《劳动合同法》解除劳动合同的强制性规定
  建议：按《劳动合同法》第四章重新拟定解除条款
  ```
</checkpoint>

</type>

## 自动识别规则

如果用户未指定合同类型，按以下优先级识别：

1. **扫描合同标题和首段**：
   - 标题含"买卖/购销/采购/供货" → 买卖合同
   - 标题含"租赁/租房/出租" → 租赁合同
   - 标题含"服务/开发/咨询/设计/外包/技术" → 服务合同
   - 标题含"劳动/聘用/劳务/入职" → 劳动合同

2. **如果标题无法判断**，扫描核心条款关键词：
   - 出现"货物/交付/验收/所有权/价款" → 买卖合同
   - 出现"租赁/租金/押金/续租" → 租赁合同
   - 出现"服务/SLA/开发/知识产权/源代码" → 服务合同
   - 出现"试用期/工资/社保/竞业/解除" → 劳动合同

3. **如果仍然无法判断** → 使用通用模板（仅使用 review-rules.md 中的四项基础审查）

4. **识别结果告知用户**：在报告开头注明"识别合同类型：XX合同"；如使用通用模板，注明"合同类型：通用"
