# 🎯 Redis 五种基础数据结构

**这个知识点要回答：Redis 支持哪五种数据结构？各自的特点和适用场景是什么？**

---

## ✍️ 自测

① String 类型的特点是什么？最大能存多大？常用场景有哪些？


② Hash 相比 String 存储对象有什么优势？


③ List 的常用场景是什么？支持哪些操作？


④ Set 和 Sorted Set 有什么区别？分别适合什么场景？


---

## ✅ 参考答案

① **String（字符串）**：最简单的类型，可以存字符串、数字或二进制数据，最大 **512MB**。常用场景：缓存 HTML 片段、计数器（INCR 原子操作）

② **Hash（哈希）**：键值对集合，适合存储对象。比 String 更省内存，因为可以**单独读写某个字段**而不需要整个序列化/反序列化

③ **List（列表）**：有序字符串列表，支持**两端插入**（LPUSH/RPUSH）。常用场景：消息队列（LPUSH+BRPOP）、最新消息列表（LRANGE）

④ **Set（集合）**：无序唯一集合，支持**交集、并集、差集**运算。适用：标签系统、好友关系。**Sorted Set（有序集合）**：每个元素带 **score 分数**，按分数排序。适用：排行榜、延时队列
