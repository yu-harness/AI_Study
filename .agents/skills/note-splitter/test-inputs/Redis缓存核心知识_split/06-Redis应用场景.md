# 🎯 Redis 典型应用场景

**这个知识点要回答：Redis 在实际项目中有哪些常见的应用场景？**

---

## ✍️ 自测

① Redis 实现分布式 session 共享的原理是什么？


② Redis 如何实现计数器功能？用了什么命令？


③ Redis 实现分布式锁的原理是什么？需要注意什么？


④ Redis 实现排行榜功能用了什么数据结构？


---

## ✅ 参考答案

① **会话缓存**：将用户的 session 数据存入 Redis，多个应用服务器共享同一个 Redis 实例。用户请求无论路由到哪台服务器，都能从 Redis 获取到 session 数据，解决分布式 session 不一致问题

② **计数器**：使用 **INCR** 命令对 key 做原子自增。应用场景：视频播放量、点赞数、文章阅读量。INCR 命令是原子操作，高并发下不会出现数据竞争

③ **分布式锁**：使用 **SETNX** 命令（SET if Not eXists）+ Lua 脚本实现。流程：SETNX lock_key value → 成功则获取锁执行业务 → 执行完用 Lua 脚本原子释放（校验 value 防误删）。注意要设置**超时时间**防止死锁

④ **排行榜**：使用 **Sorted Set（有序集合）** 数据结构。每个元素带一个 score 分数，Redis 自动按分数排序。用 `ZADD` 添加/更新分数，`ZREVRANGE` 获取排名 Top N
