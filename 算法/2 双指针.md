[11](https://leetcode.cn/problems/container-with-most-water/)
`min(height[left], height[right]) * (right - left)` 就是这两条竖线加上 x 轴围出的容积，高度由较矮的那条线决定

[15](https://leetcode.cn/problems/3sum/)
排序后依次固定第一个数，在它右侧的区间放左右两个指针，每次把三个数的和与 0 比较：结果小于 0 说明和还不够大，左指针往右移；结果大于 0 说明和超出了，右指针往左移；结果等于 0 就记录下来，两个指针各走一步，并跳过各自的重复值。

[42](https://leetcode.cn/problems/trapping-rain-water/)
水量 = min(左边最高, 右边最高) - 当前高度
对每一个位置，能接住的雨水等于它左侧最高柱子和右侧最高柱子中较矮的那个，减去它自身的高度；双指针从两端向中间推进，哪一侧当前的最高值更小，就先确定那一侧那一格能接多少水。这个做法成立的前提是：较矮的那一侧被较高一侧挡住，它自己的最高值就是决定它水量的那个上界。
