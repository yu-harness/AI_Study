# [94. 二叉树的中序遍历](https://leetcode.cn/problems/binary-tree-inorder-traversal/)

中序 = 左 → 根 → 右。

```python
class Solution:
    def inorderTraversal(self, root):
        res, stack, cur = [], [], root
        while cur or stack:
            while cur:                 # 一路向左压栈
                stack.append(cur)
                cur = cur.left
            cur = stack.pop()          # 弹出即访问
            res.append(cur.val)
            cur = cur.right            # 转向右子树
        return res
```

递归版三行就能写完，但面试要的是**迭代版**——用栈手动模拟递归。

时间 $O(n)$，空间 $O(h)$，$h$ 是树高。

# [104. 二叉树的最大深度](https://leetcode.cn/problems/maximum-depth-of-binary-tree/)

```python
class Solution:
    def maxDepth(self, root):
        if not root:
            return 0
        return 1 + max(self.maxDepth(root.left), self.maxDepth(root.right))
```

记住这一行：`self.maxDepth(...)` 里的 `self` 不能省，省了就是上面那个报错。

一句话：**深度 = 1 + 较深的那棵子树**，空树返回 0 是递归出口。

时间 $O(n)$，空间 $O(h)$。BFS 也能做：数层数。

# [226. 翻转二叉树](https://leetcode.cn/problems/invert-binary-tree/)

```python
class Solution:
    def invertTree(self, root):
        if not root:
            return None
        root.left, root.right = self.invertTree(root.right), self.invertTree(root.left)
        return root
```

注意右边递归结果给 left：**交换的是两棵子树，不是值**。前序、后序都行；中序会出错（同一个孩子被翻两次）。

时间 $O(n)$，空间 $O(h)$。

# [101. 对称二叉树](https://leetcode.cn/problems/symmetric-tree/)

判断左右两棵子树是否互为镜像：`a.left` 比 `b.right`，`a.right` 比 `b.left`。

```python
class Solution:
    def isSymmetric(self, root):
        def check(a, b):
            if not a and not b:
                return True
            if not a or not b or a.val != b.val:
                return False
            return check(a.left, b.right) and check(a.right, b.left)

        return check(root.left, root.right) if root else True
```

`if not a and not b: return True` 判断的是**两边同时为空**——这是递归的出口：两条线一路走到底都没节点了，说明这一段完全对称，返回 True。

只要出现下面三种情况之一，就判不对称：

| 情况 | 结果 |
| --- | --- |
| `a` 空、`b` 不空（或反过来） | False，形状不对称 |
| 都非空但 `a.val != b.val` | False，值不对称 |
| 都非空、值相同 | 继续向下比较交叉的两对 |

所以顺序不能颠倒：**先判"都空"，再判"只有一个空"，最后比值**。

易错：**不能**用「中序遍历结果是否回文」判断，值相同不代表结构镜像。

时间 $O(n)$，空间 $O(h)$。

# [543. 二叉树的直径](https://leetcode.cn/problems/diameter-of-binary-tree/)

直径 = 某节点左右深度之和的最大值，**不一定过根**。

```python
class Solution:
    def diameterOfBinaryTree(self, root):
        best = 0

        def depth(node):
            nonlocal best
            if not node:
                return 0
            left = depth(node.left)
            right = depth(node.right)
            best = max(best, left + right)     # 以当前节点为拐点的路径
            return 1 + max(left, right)        # 交给父节点的是单边深度

        depth(root)
        return best
```

`nonlocal best` 是什么：它声明「`best` 不是这个内层函数的局部变量，而是外层函数 `diameterOfBinaryTree` 的那个」——**只有声明了才能在内层函数里给它赋值**。

不加会怎样：

```python
def f():
    x = 0
    def g():
        x += 1          # 报错 UnboundLocalError
    g()
```

Python 看到内层函数里对 `x` 赋值，就认定 `x` 是本层局部变量；但赋值前它还没有值，于是报错。加上 `nonlocal x` 才指向外层。

三条规则记牢：

| 在内层函数里做什么 | 要不要 nonlocal |
| --- | --- |
| 只读外层变量的值 | 不要 |
| **给它重新赋值**（`x += 1`、`best = max(...)`） | **要** |
| 修改容器内容（`list.append`、`dict[k] = v`） | 不要（改的是对象本身） |

本题的 `best = max(best, left + right)` 属于第二种，所以必须写 `nonlocal best`。

关键在**两个出口含义不同**：给父节点返回「一边的深度」，更新答案用「两边相加」。

时间 $O(n)$，空间 $O(h)$。

# [102. 二叉树的层序遍历](https://leetcode.cn/problems/binary-tree-level-order-traversal/)

```python
class Solution:
    def levelOrder(self, root):
        from collections import deque
        if not root:
            return []
        res, q = [], deque([root])
        while q:
            level = []
            for _ in range(len(q)):        # 先锁定本层节点数
                node = q.popleft()
                level.append(node.val)
                if node.left:
                    q.append(node.left)
                if node.right:
                    q.append(node.right)
            res.append(level)
        return res
```

`for _ in range(len(q))` 是分层核心——**先记住本层长度**，新入队的下一层才不会被算进来。

时间 $O(n)$，空间 $O(w)$，$w$ 为最大宽度。

# [108. 将有序数组转换为二叉搜索树](https://leetcode.cn/problems/convert-sorted-array-to-binary-search-tree/)

取中点当根，左右递归，天然平衡。

```python
class Solution:
    def sortedArrayToBST(self, nums):
        def build(lo, hi):
            if lo > hi:
                return None
            mid = (lo + hi) // 2
            node = TreeNode(nums[mid])
            node.left = build(lo, mid - 1)
            node.right = build(mid + 1, hi)
            return node

        return build(0, len(nums) - 1)
```

取中点使左右元素数最多差 1，树高严格 $O(\log n)$。

时间 $O(n)$，空间 $O(\log n)$。

# [98. 验证二叉搜索树](https://leetcode.cn/problems/validate-binary-search-tree/)

只比父子不够，必须保证**整棵左子树都小于根**。

```python
class Solution:
    def isValidBST(self, root):
        def check(node, low, high):
            if not node:
                return True
            if node.val <= low or node.val >= high:
                return False
            return check(node.left, low, node.val) and check(node.right, node.val, high)

        return check(root, float("-inf"), float("inf"))
```

# [230. 二叉搜索树中第 K 小的元素](https://leetcode.cn/problems/kth-smallest-element-in-a-bst/)

BST 中序即升序，走到第 k 个就停。

```python
class Solution:
    def kthSmallest(self, root, k):
        stack, cur = [], root
        while True:
            while cur:
                stack.append(cur)
                cur = cur.left
            cur = stack.pop()
            k -= 1
            if k == 0:
                return cur.val
            cur = cur.right
```

时间 $O(h+k)$，空间 $O(h)$。若频繁查询，可在节点上维护「子树大小」，做到 $O(h)$。

# [199. 二叉树的右视图](https://leetcode.cn/problems/binary-tree-right-side-view/)

层序遍历，每层只留最后一个。

```python
class Solution:
    def rightSideView(self, root):
        from collections import deque
        res, q = [], deque([root] if root else [])
        while q:
            n = len(q)
            for i in range(n):
                node = q.popleft()
                if i == n - 1:
                    res.append(node.val)     # 本层最后一个
                if node.left:
                    q.append(node.left)
                if node.right:
                    q.append(node.right)
        return res
```

时间 $O(n)$，空间 $O(w)$。

# [114. 二叉树展开为链表](https://leetcode.cn/problems/flatten-binary-tree-to-linked-list/)  ❓

要求原地展开成「只有右孩子」的链表，顺序为前序。

```python
class Solution:
    def flatten(self, root):
        cur = root
        while cur:
            if cur.left:
                pre = cur.left
                while pre.right:            # 找左子树最右节点
                    pre = pre.right
                pre.right = cur.right       # 原右子树接到它后面
                cur.right = cur.left        # 左子树整体移到右边
                cur.left = None
            cur = cur.right
```

思路：把左子树塞到「根」和「右子树」之间，再一路往右走。

时间 $O(n)$（每个节点最多访问两次），空间 $O(1)$。

# [105. 从前序与中序遍历序列构造二叉树](https://leetcode.cn/problems/construct-binary-tree-from-preorder-and-inorder-traversal/) ❓

前序第一个是根；在中序里定位根，左边是左子树、右边是右子树。

```python
class Solution:
    def buildTree(self, preorder, inorder):
        idx = {v: i for i, v in enumerate(inorder)}   # 值 → 中序下标

        def build(pre_lo, in_lo, in_hi):
            if in_lo > in_hi:
                return None
            root_val = preorder[pre_lo]
            root = TreeNode(root_val)
            mid = idx[root_val]
            left_size = mid - in_lo
            root.left = build(pre_lo + 1, in_lo, mid - 1)
            root.right = build(pre_lo + 1 + left_size, mid + 1, in_hi)
            return root

        return build(0, 0, len(inorder) - 1)
```

关键是 `pre_lo + 1 + left_size`：**右子树根在前序中的位置 = 根 + 1 + 左子树节点数**。

时间 $O(n)$，空间 $O(n)$。中序 + 后序同理，只是根从后序末尾取。

# [437. 路径总和 III](https://leetcode.cn/problems/path-sum-iii/) ❓

路径可从任意节点往下走，求条数。用**前缀和 + 回溯**：走到节点时看「当前前缀和 − target」出现过几次。

```python
class Solution:
    def pathSum(self, root, targetSum):
        from collections import defaultdict
        count = defaultdict(int)
        count[0] = 1                      # 空前缀：处理"从根开始就满足"

        def dfs(node, cur):
            if not node:
                return 0
            cur += node.val
            res = count[cur - targetSum]  # 以当前节点结尾的合法路径数
            count[cur] += 1
            res += dfs(node.left, cur) + dfs(node.right, cur)
            count[cur] -= 1               # 回溯：离开该子树要撤销
            return res

        return dfs(root, 0)
```

为什么要回溯：`count` 记录的是**当前这条根到节点的路径**上的前缀和，不同分支不能互相污染。

时间 $O(n)$，空间 $O(h)$。

# [236. 二叉树的最近公共祖先](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/) ❓

```python
class Solution:
    def lowestCommonAncestor(self, root, p, q):
        if root in (None, p, q):
            return root
        left = self.lowestCommonAncestor(root.left, p, q)
        right = self.lowestCommonAncestor(root.right, p, q)
        if left and right:          # 两侧各找到一个 → 当前就是分叉点
            return root
        return left or right        # 只找到一侧，往上传递
```

理解要点：函数返回「这棵子树里找到的 p 或 q，或它们的 LCA」。两侧都非空，说明 p、q 分居左右，当前节点即答案。

时间 $O(n)$，空间 $O(h)$。若是 BST，可按值大小决定走向，$O(h)$。

# [124. 二叉树中的最大路径和](https://leetcode.cn/problems/binary-tree-maximum-path-sum/)

与 543 同一套路：更新答案用「左右都走」，返回值只能「选一边」。

```python
class Solution:
    def maxPathSum(self, root):
        best = float("-inf")

        def gain(node):
            nonlocal best
            if not node:
                return 0
            left = max(gain(node.left), 0)    # 负数不如不走
            right = max(gain(node.right), 0)
            best = max(best, node.val + left + right)   # 以当前节点为最高点
            return node.val + max(left, right)          # 只能给父节点一条边

        gain(root)
        return best
```

两处 `max(..., 0)` 是重点：**子树贡献为负直接舍弃**，否则会拖低答案。

时间 $O(n)$，空间 $O(h)$。
