# 9 图论

网格题本质是图：每个格子是一个节点，上下左右是边。这类题只有三个模板——**DFS 淹岛**、**多源 BFS 求最短**、**拓扑排序判环**，另外加一个 Trie（前缀树）。

# [200. 岛屿数量](https://leetcode.cn/problems/number-of-islands/)

遇到一个 '1' 就把答案 +1，然后**用 DFS 把整座岛淹掉**（改成 '0'），避免重复计数。

```python
class Solution:
    def numIslands(self, grid):
        if not grid:
            return 0
        m, n = len(grid), len(grid[0])

        def dfs(i, j):
            if i < 0 or i >= m or j < 0 or j >= n or grid[i][j] != '1':
                return
            grid[i][j] = '0'                 # 淹掉，防止再次访问
            dfs(i - 1, j); dfs(i + 1, j)
            dfs(i, j - 1); dfs(i, j + 1)

        count = 0
        for i in range(m):
            for j in range(n):
                if grid[i][j] == '1':
                    count += 1
                    dfs(i, j)
        return count
```

时间 $O(mn)$：每个格子最多被访问一次；空间 $O(mn)$：递归栈最坏是整片网格。

**坑**：`grid[i][j] = '0'` 必须写在递归之前，否则会与相邻格来回递归，直接爆栈。

# [994. 腐烂的橘子](https://leetcode.cn/problems/rotting-oranges/)

**多源 BFS**：把所有腐烂橘子同时入队，一层一层往外扩，扩完的层数就是分钟数。

```python
from collections import deque

class Solution:
    def orangesRotting(self, grid):
        m, n = len(grid), len(grid[0])
        q = deque()
        fresh = 0
        for i in range(m):
            for j in range(n):
                if grid[i][j] == 2:
                    q.append((i, j))         # 所有腐烂橘子一起入队（多源）
                elif grid[i][j] == 1:
                    fresh += 1

        minutes = 0
        while q and fresh > 0:               # 还有新鲜橘子才继续扩
            for _ in range(len(q)):          # 锁定这一层
                i, j = q.popleft()
                for di, dj in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                    x, y = i + di, j + dj
                    if 0 <= x < m and 0 <= y < n and grid[x][y] == 1:
                        grid[x][y] = 2
                        fresh -= 1
                        q.append((x, y))
            minutes += 1
        return minutes if fresh == 0 else -1
```

时间 $O(mn)$，空间 $O(mn)$。

**两个坑**：`while q and fresh > 0` 少了 `fresh > 0` 会多算一分钟；最后要判 `fresh == 0`，否则有橘子永远烂不掉，返回 $-1$。

# [207. 课程表](https://leetcode.cn/problems/course-schedule/) ❓

本质是**判断有向图有没有环**。用拓扑排序：每次取入度为 0 的课，取完把它的后续课入度减一；能取完所有课就没环。

```python
from collections import deque

class Solution:
    def canFinish(self, numCourses, prerequisites):
        graph = [[] for _ in range(numCourses)]
        indeg = [0] * numCourses
        for a, b in prerequisites:           # 先修 b，才能学 a
	            graph[b].append(a)
            indeg[a] += 1

        q = deque(i for i in range(numCourses) if indeg[i] == 0)
        seen = 0
        while q:
            cur = q.popleft()
            seen += 1
            for nxt in graph[cur]:
                indeg[nxt] -= 1
                if indeg[nxt] == 0:
                    q.append(nxt)
        return seen == numCourses
```

时间 $O(V+E)$，空间 $O(V+E)$。

**判据**：能拓扑排序完 = 无环 = 可以修完；排不完说明剩下的课互相依赖，形成环。

DFS 版用三色标记：`0` 未访问、`1` 在栈中、`2` 已完成，走到 `1` 就说明有环。

# [208. 实现 Trie（前缀树）](https://leetcode.cn/problems/implement-trie-prefix-tree/)

每个节点存两样东西：**子节点字典**（字符 → 下一个节点）和 **`is_end` 标记**（是否有单词在这里结束）。

```python
class Trie:
    def __init__(self):
        self.children = {}
        self.is_end = False

    def insert(self, word):
        node = self
        for ch in word:
            if ch not in node.children:
                node.children[ch] = Trie()
            node = node.children[ch]
        node.is_end = True

    def search(self, word):
        node = self._walk(word)
        return node is not None and node.is_end

    def startsWith(self, prefix):
        return self._walk(prefix) is not None

    def _walk(self, s):
        node = self
        for ch in s:
            if ch not in node.children:
                return None
            node = node.children[ch]
        return node
```

时间：插入与查询都是 $O(L)$（$L$ 为字符串长度）；空间 $O(\text{总字符数})$。

**两个易错点**：`search` 必须同时检查 `is_end`，否则 `app` 会被判为存在过 `apple`；`startsWith` 只要求走通路径，不看 `is_end`。把两处公共的“走前缀”抽成 `_walk`，一处改动两处受益。
