#  [3](https://leetcode.cn/problems/longest-substring-without-repeating-characters/)

滑动窗口：右指针逐个字符向右扩展，一旦遇到“在当前窗口内已经出现过”的字符，就让左指针直接跳到该字符上次出现位置的下一位（不用一格一格挪），窗口内始终无重复，最大窗口宽度就是答案。

```python
def lengthOfLongestSubstring(s: str) -> int:
    last = {}              # 字符 -> 上次出现的下标
    left = ans = 0
    for right, ch in enumerate(s):
        if ch in last and last[ch] >= left:   # 上次出现还在窗口内
            left = last[ch] + 1
        last[ch] = right
        ans = max(ans, right - left + 1)
    return ans
```

判断条件里的 `last[ch] >= left` 不能省略，否则像 `abba` 这种情况，左指针会被拉回到到已经过期、不在窗口内的字符后面。时间复杂度 $O(n)$，空间复杂度 $O(|\Sigma|)$，即字符集大小。

# [438](https://leetcode.cn/problems/find-all-anagrams-in-a-string/description/?envType=study-plan-v2&envId=top-100-liked)

固定长度滑动窗口：窗口宽度固定为 `len(p)`，每步新进一个字符、从左边移出一个字符；只要窗口中 26 个字母的统计结果与 `p` 的统计结果完全一致，这个窗口的起点就是一个答案。

```python
def findAnagrams(s: str, p: str) -> list[int]:
    n, m = len(s), len(p)
    if n < m:
        return []
    need = [0] * 26
    for ch in p:
        need[ord(ch) - 97] += 1
    window = [0] * 26
    res = []
    for i, ch in enumerate(s):
        window[ord(ch) - 97] += 1
        if i >= m:                        # 窗口超过 m 就移出最左边
            window[ord(s[i - m]) - 97] -= 1
        if window == need:                # i 是窗口右端
            res.append(i - m + 1)
    return res
```

要注意移出的条件是 `i >= m`，不能写成 `i > m`；否则第一次形成宽度为 m 的窗口时，就会提前减少一个字符。复杂度为 $O(26n)$，也就是 $O(n)$，空间为 $O(1)$。
