# [560](https://leetcode.cn/problems/subarray-sum-equals-k/description/?envType=study-plan-v2&envId=top-100-liked)

前缀和 + 哈希表：遍历时维护 `pre` = 从 0 到当前的元素和，如果之前出现过 `pre - k` 这个前缀和，那么这段之间就有一个子数组的和为 k；先用哈希表记录下每个前缀和出现过的次数，再直接查询即可。

```python
def subarraySum(nums: list[int], k: int) -> int:
    cnt = {0: 1}                 # 普通 dict，不用 defaultdict
    pre = ans = 0
    for x in nums:
        pre += x
        ans += cnt.get(pre - k, 0)   # 查不到就取 0，不插入键
        cnt[pre] = cnt.get(pre, 0) + 1
    return ans
```

- `cnt = {0: 1}` 表示「空前缀」，对应从头开始的子数组；漏掉这一项会漏算所有起点为 0 且和恰为 k 的段。
- **先查后写**：必须先 `ans += cnt[pre - k]`，再把当前 `pre` 写进表。顺序反了，k = 0 时当前元素会和自己配对，结果偏大。
- 命中时累加的是 `cnt[pre - k]` 而不是 +1：同一前缀和可能出现多次（如 `7` 出现两次），每次都要单独算一段。
- 数组允许负数，前缀和不单调，所以**不能用滑动窗口**，只能靠 **前缀和哈希**。
- 复杂度 O(n) 时间、O(n) 空间；最坏情况前缀和全不相同，哈希表存 n 个键。

# [239](https://leetcode.cn/problems/sliding-window-maximum/?envType=study-plan-v2&envId=top-100-liked)

维护一个**单调递减双端队列**，队列里存的是下标，对应的值从队头到队尾依次递减；队头就是当前窗口最大值。所以每来一个数，队尾所有小于等于它的都弹出（它们不可能再成为最大值），队头如果滑出窗口也弹出。

```python
from collections import deque

def maxSlidingWindow(nums: list[int], k: int) -> list[int]:
    q = deque()            # 存下标，值从队头到队尾递减
    res = []
    for i, x in enumerate(nums):
        while q and nums[q[-1]] <= x:   # 队尾小的没用，弹掉
            q.pop()
        q.append(i)
        if q[0] <= i - k:               # 队头已滑出窗口
            q.popleft()
        if i >= k - 1:
            res.append(nums[q[0]])
    return res
```

要注意队列存的是**下标**而不是数值：判断元素是否滑出窗口时，要比较下标，而不能比较值；而且必须在取 `q[0]` 之前先做一次过期检查。每个下标最多入队一次、出队一次，所以时间复杂度是 $O(n)$，空间复杂度是 $O(k)$。
# [76](https://leetcode.cn/problems/minimum-window-substring/description/?envType=study-plan-v2&envId=top-100-liked)

用**可变长滑动窗口加缺失计数**：右指针一直向右扩展，`missing` 记录还差多少个字符（含重复）；当它变成 0 时，窗口已经覆盖了 `t`，于是从左边尽量收缩——只要某个字符在窗口里是多余的，就把它从窗口中移出。

```python
from collections import Counter

def minWindow(s: str, t: str) -> str:
    need = Counter(t)
    missing = len(t)                 # 还缺多少个字符（含重复）
    left = 0
    best = (0, float("inf"))         # (左端点, 长度)
    for right, ch in enumerate(s):
        if need[ch] > 0:
            missing -= 1
        need[ch] -= 1

        while missing == 0:          # 已覆盖，尝试收缩
            if right - left + 1 < best[1]:
                best = (left, right - left + 1)
            need[s[left]] += 1       # 移出左端字符
            if need[s[left]] > 0:    # 移出后不够了，跳出
                missing += 1
            left += 1

    l, w = best
    return "" if w == float("inf") else s[l:l + w]
```

`need` 里负数表示「这个字符多出来了」，收缩时正是靠它判断能不能安全地丢掉左端。要注意的是，缺失计数要**带着重复次数一起算**：`need[ch] > 0` 时才减 `missing`，否则像 `t = "aa"` 这种情况就会少算。左右指针各自只前进一次，复杂度为 $O(m+n)$，空间为 $O(|\Sigma|)$。
