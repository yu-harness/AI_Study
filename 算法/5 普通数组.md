# [53. 最大子数组和](https://leetcode.cn/problems/maximum-subarray/)

**Kadane 算法**
	只看“以当前位置结尾的最大和”，前面那一段如果是负的，就干脆不要它，从当前元素重新开始。
$$dp[i] = \max(nums[i],\; dp[i-1] + nums[i])$$
```python
def maxSubArray(nums):
    cur = best = nums[0]
    for x in nums[1:]:
        cur = max(x, cur + x)      # 前面拖后腿就断开，从 x 重新起
        best = max(best, cur)
    return best
```

`cur` 是“必须包含当前元素”的最大和，`best` 是历史最高。负数会把后面的和拖小，所以一旦 `cur + x < x`（即 `cur < 0`），保留前面只会更差，直接归零重开。

因为题目允许子数组从任意处开始，不要求包含当前元素，所以答案是对所有 `i` 取 `dp[i]` 的最大值，而不能直接取最后一个。

时间 $O(n)$、空间 $O(1)$，一趟扫完。注意初始值要设成 `nums[0]` 而不是 0，否则全负数数组会返回 0。

# [56. 合并区间](https://leetcode.cn/problems/merge-intervals/)

先按**左端点排序**，排完之后重叠的区间一定挨在一起，然后从**左往右扫一遍往**结果里并。

```python
def merge(intervals):
    intervals.sort(key=lambda x: x[0])      # 按起点升序
    res = []
    for s, e in intervals:
        if res and s <= res[-1][1]:         # 和上一段有重叠
            res[-1][1] = max(res[-1][1], e) # 只延长右端点
        else:
            res.append([s, e])              # 断开了，另起一段
    return res
```

关键是排序这一步：`[1,3],[2,6],[8,10]` 排完顺序天然就是扫描顺序，不用回头再比。

`max` 不能省，因为后面那段可能被完全包含，比如 `[1,10]` 后再来 `[2,3]`，右端点不该被改小。

判断用 `s <= res[-1][1]`，等号表示端点相接也算重叠，`[1,4]` 和 `[4,5]` 要并成 `[1,5]`；如果题目要求首尾相接不算重叠，改成分号左边用 `<`。

排序花 $O(n\log n)$，扫描是 $O(n)$，总体 $O(n\log n)$，额外空间 $O(1)$（不计返回值）。
# [189. 轮转数组](https://leetcode.cn/problems/rotate-array/)

最省空间的做法是**三次反转**，不用额外数组，原地交换。

```python
def rotate(nums, k):
    n = len(nums)
    k %= n                      # k 可能比 n 大，先取模
    def rev(i, j):
        while i < j:
            nums[i], nums[j] = nums[j], nums[i]
            i, j = i + 1, j - 1
    rev(0, n - 1)               # 1. 整体反转
    rev(0, k - 1)               # 2. 前 k 个反转
    rev(k, n - 1)               # 3. 剩下的反转
```

道理是：右移 k 位，就是**最后 k 个元素搬到最前面**。整体反转正好把这 k 个送到了头部，但顺序是倒的；再对前后两段各反转一次，把顺序洗回来。


# [238.除了自身以外数组的乘积](https://leetcode.cn/problems/product-of-array-except-self/?envType=study-plan-v2&envId=top-100-liked)

答案是「左边的积」乘「右边的积」，两趟扫描搞定，不用除法——因为数组里可能有 0，除法会翻车。

```python
def productExceptSelf(nums):
    n = len(nums)
    res = [1] * n
    for i in range(1, n):                 # 第一趟：res[i] = 左边所有元素之积
        res[i] = res[i - 1] * nums[i - 1]
    suffix = 1
    for i in range(n - 1, -1, -1):        # 第二趟：把右边的积累乘进来
        res[i] *= suffix
        suffix *= nums[i]
    return res
```

`answer[i]` 本质就是「除我以外所有人」，可以拆成「我左边的人」和「我右边的人」两组，分别算再乘起来。

第一趟从左走，`res[i]` 只累积到 `i-1`，天然不含自己；第二趟从右走，用一个变量 `suffix` 攒右边，边攒边乘进 `res[i]`，这样省掉了两个额外数组。

`res` 是必须返回的结果，所以空间只算常量级 $O(1)$，时间两趟 $O(n)$。

# [41. 缺失的第一个正数](https://leetcode.cn/problems/first-missing-positive/description/?envType=study-plan-v2&envId=top-100-liked)

核心思路是**把数组本身当哈希表用**：让数值 `x` 待在下标 `x-1` 上，然后从头扫，第一个 `nums[i] != i+1` 的位置就是答案。

```python
def firstMissingPositive(nums):
    n = len(nums)
    for i in range(n):
        while 1 <= nums[i] <= n and nums[nums[i] - 1] != nums[i]:
            j = nums[i] - 1
            nums[i], nums[j] = nums[j], nums[i]   # 把 x 换到 x-1 的位置
    for i in range(n):
        if nums[i] != i + 1:
            return i + 1
    return n + 1                                  # 1..n 都齐了
```

先想清楚答案的范围：数组只有 $n$ 个数，所以最小的缺口一定落在 $1 \sim n+1$ 之间，别的值根本不用管，`<= 0` 和 `> n` 直接跳过。

`while` 而不是 `if`，因为换过来的新数可能还得继续往它的位置上挪；循环条件里的 `nums[nums[i]-1] != nums[i]` 是**防止重复值**互相换导致死循环。

每个数最多被交换到正确位置一次，所以虽然是双层循环，总交换次数不超过 $n$，时间仍是 $O(n)$，空间 $O(1)$。
