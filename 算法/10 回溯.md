# 10 回溯

回溯就是**在决策树上做 DFS**：每层做一个选择，进下一层，回来时把选择撤销。所有题只差三件事——**什么时候收答案**（每个节点收，还是叶子才收）、**下一层从哪开始**（用 `start` 控制顺序，还是用 `used` 标记）、**怎么剪枝**。

```python
def dfs(路径, 选择列表):
    if 满足结束条件:
        res.append(路径[:])       # 必须拷贝，path 后面还会变
        return
    for 选择 in 选择列表:
        if 需要剪枝: continue
        做选择                      # path.append / used[i]=True
        dfs(路径, 新的选择列表)
        撤销选择                    # path.pop() / used[i]=False
```

# [46. 全排列](https://leetcode.cn/problems/permutations/)

顺序有关，所以用 `used` 记录**哪些元素已经被用掉**；层数等于数组长度时收答案。

```python
class Solution:
    def permute(self, nums):
        res, path = [], []
        used = [False] * len(nums)

        def dfs():
            if len(path) == len(nums):      # 叶子才收：所有元素都排完了
                res.append(path[:])
                return
            for i, x in enumerate(nums):
                if used[i]:                 # 同一支上不能重复用
                    continue
                used[i] = True
	                path.append(x) 
                dfs()
                path.pop()                  # 撤销
                used[i] = False

        dfs()
        return res
```

时间 $O(n\cdot n!)$：共 $n!$ 个答案，每个拷贝长度 $n$；空间 $O(n)$：递归深度加 `used`。

**坑**：`res.append(path)` 会存引用，最后全是空列表，必须写 `path[:]`。

# [78. 子集](https://leetcode.cn/problems/subsets/)

顺序无关，所以用 `start` 保证**只往后挑**，不会出现 `[1,2]` 和 `[2,1]` 重复；并且**每个节点都是答案**，不用等到叶子。

```python
class Solution:
    def subsets(self, nums):
        res, path = [], []

        def dfs(start):
            res.append(path[:])             # 进节点就收，包括空集
            for i in range(start, len(nums)):
                path.append(nums[i])
                dfs(i + 1)                  # 传 i+1：只能选后面的
                path.pop()

        dfs(0)
        return res
```

时间 $O(n\cdot 2^n)$：$2^n$ 个子集，每个拷贝长度最多 $n$；空间 $O(n)$。

**坑**：`dfs(i + 1)` 写成 `dfs(start + 1)` 会漏掉一部分组合；写成 `dfs(i)` 会无限循环。

# [17. 电话号码的字母组合](https://leetcode.cn/problems/letter-combinations-of-a-phone-number/)

每一位数字对应若干字母，**层数就是数字个数**，每层枚举这个数字对应的字母。

```python
class Solution:
    def letterCombinations(self, digits):
        if not digits:
            return []
        table = {
            '2': 'abc', '3': 'def', '4': 'ghi', '5': 'jkl',
            '6': 'mno', '7': 'pqrs', '8': 'tuv', '9': 'wxyz',
        }
        res = []

        def dfs(i, path):
            if i == len(digits):            # 每个数字都处理完了
                res.append(path)
                return
            for ch in table[digits[i]]:
                dfs(i + 1, path + ch)       # 字符串不可变，天然自带撤销

        dfs(0, '')
        return res
```

时间 $O(4^n\cdot n)$：每层最多 4 个分支，答案长度 $n$；空间 $O(n)$：只用递归栈。

**坑**：空字符串要单独返回 `[]`，否则会返回 `['']`。

# [39. 组合总和](https://leetcode.cn/problems/combination-sum/)

元素**可以重复使用**，所以递归传 `i` 而不是 `i+1`；排序后一旦超过 `rest` 就可以 `break`，这是最有效的剪枝。

```python
class Solution:
    def combinationSum(self, candidates, target):
        res, path = [], []
        candidates.sort()                   # 排序才能 break 剪枝

        def dfs(start, rest):
            if rest == 0:
                res.append(path[:])
                return
            for i in range(start, len(candidates)):
                if candidates[i] > rest:    # 后面只会更大，直接停
                    break
                path.append(candidates[i])
                dfs(i, rest - candidates[i])   # 传 i：同一个数可以再选
                path.pop()

        dfs(0, target)
        return res
```

时间 $O(S)$，$S$ 是所有解的长度之和；空间 $O(\text{target}/\min)$ 的递归深度。

**坑**：传 `i + 1` 就变成“每个数只能用一次”（第 40 题）；不排序就没法 `break` 剪枝。

# [22. 括号生成](https://leetcode.cn/problems/generate-parentheses/)

不用枚举所有括号串再判合法，**边生成边保证合法**：左括号不足 $n$ 个就能放，右括号少于左括号时才能放。

```python
class Solution:
    def generateParenthesis(self, n):
        res = []

        def dfs(path, left, right):
            if len(path) == 2 * n:
                res.append(path)
                return
            if left < n:                    # 左括号还有额度
                dfs(path + '(', left + 1, right)
            if right < left:                # 右括号不能多于左括号
                dfs(path + ')', left, right + 1)

        dfs('', 0, 0)
        return res
```

时间 $O(\frac{4^n}{\sqrt n})$：第 $n$ 个卡特兰数；空间 $O(n)$：递归深度。

**坑**：`right < left` 写成 `right < n` 就会生成 `)()` 这类非法串。

# [79. 单词搜索](https://leetcode.cn/problems/word-search/)

在网格上走，路径是**一条不能回头的链**，所以标记用“临时改写 + 回溯还原”，而不是全局 `visited`。

```python
class Solution:
    def exist(self, board, word):
        m, n = len(board), len(board[0])

        def dfs(i, j, k):
            if k == len(word):              # 每个字符都匹配上了
                return True
            if not (0 <= i < m and 0 <= j < n) or board[i][j] != word[k]:
                return False
            board[i][j] = '#'               # 标记本格已用，防止原地打转
            found = (dfs(i + 1, j, k + 1) or dfs(i - 1, j, k + 1)
                     or dfs(i, j + 1, k + 1) or dfs(i, j - 1, k + 1))
            board[i][j] = word[k]           # 还原，别的路径还要用
            return found

        for i in range(m):
            for j in range(n):
                if dfs(i, j, 0):
                    return True
        return False
```

时间 $O(mn\cdot 3^L)$：每个起点，每一步最多 3 个方向（不能回头），$L$ 是单词长度；空间 $O(L)$。

**坑**：还原时写 `board[i][j] = word[k]`，不要写 `'#'` 的相反数之类的占位符，否则原字符就丢了。

# [131. 分割回文串](https://leetcode.cn/problems/palindrome-partitioning/)

这是**切割问题**：`start` 是当前段的起点，枚举这一段的终点 `end`，只有 `s[start:end+1]` 是回文才继续切下一段。

```python
class Solution:
    def partition(self, s):
        res, path = [], []
        n = len(s)

        def is_pal(l, r):
            while l < r:
                if s[l] != s[r]:
                    return False
                l += 1
                r -= 1
            return True

        def dfs(start):
            if start == n:                  # 切到末尾，path 里是一种切法
                res.append(path[:])
                return
            for end in range(start, n):
                if not is_pal(start, end):  # 这一段不是回文，换更长的也没用
                    continue
                path.append(s[start:end + 1])
                dfs(end + 1)                # 从下一段开始切
                path.pop()

        dfs(0)
        return res
```

时间 $O(n\cdot 2^n)$：最多 $2^{n-1}$ 种切法，每种判断回文 $O(n)$；空间 $O(n)$。

**坑**：`dfs(end + 1)` 写 `dfs(start + 1)` 会变成逐字符切；判断回文可以预处理成 $O(1)$ 查表（`dp[i][j]`）来降复杂度。

# [51. N 皇后](https://leetcode.cn/problems/n-queens/)

一行一行放皇后，所以**行冲突天然不存在**；只需用三个集合排除**列、主对角线、副对角线**。

```python
class Solution:
    def solveNQueens(self, n):
        res = []
        cols, diag1, diag2 = set(), set(), set()
        board = ['.' * n for _ in range(n)]

        def dfs(row):
            if row == n:
                res.append(board[:])
                return
            for col in range(n):
                if col in cols or row - col in diag1 or row + col in diag2:
                    continue
                cols.add(col)
                diag1.add(row - col)        # 左上到右下：row - col 相同
                diag2.add(row + col)        # 右上到左下：row + col 相同
                board[row] = '.' * col + 'Q' + '.' * (n - col - 1)
                dfs(row + 1)
                board[row] = '.' * n
                cols.remove(col)
                diag1.remove(row - col)
                diag2.remove(row + col)

        dfs(0)
        return res
```

时间 $O(n!)$：第一行 $n$ 种放法，之后逐行骤减；空间 $O(n)$：三个集合加棋盘。

**坑**：主对角线用 `row - col`、副对角线用 `row + col`，两者写反不会报错但答案全错；三个集合**必须**在递归后逐个 `remove`，漏一个就会误伤同层其他分支。
