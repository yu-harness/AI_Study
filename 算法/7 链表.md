# [160. 相交链表](https://leetcode.cn/problems/intersection-of-two-linked-lists/)

两个指针各走一条链表，**走到头就跳去对方的链表继续走**。

```python
def getIntersectionNode(headA, headB):
    a, b = headA, headB
    while a != b:
        a = a.next if a else headB     # 走完 A 就去走 B
        b = b.next if b else headA     # 走完 B 就去走 A
    return a                           # 相遇点或 None
```

道理是路程相等：设 A 独有段 $a$、B 独有段 $b$、公共段 $c$，两人都走 $a+b+c$ 步，所以要么在交点同时到，要么同时走到 `None`。

这样不需要算长度差、也不需要额外哈希表，空间 $O(1)$。

时间 $O(m+n)$，各自最多走两遍链表。

注意 `while a != b` 用的是节点身份比较（`!=` 比的是对象引用），不是比 `val`，题目要求的就是同一个节点。

用 LeetCode 那个例子：$A=[4,1,8,4,5]$，$B=[5,6,1,8,4,5]$，交点是节点 8。

**指针 a 的路线**：`4 → 1 → 8 → 4 → 5` 走完 A 共 5 步，变成 `None`，跳到 `headB` 继续 `5 → 6 → 1 → 8`，第 8 步踩到 8。

**指针 b 的路线**：`5 → 6 → 1 → 8 → 4 → 5` 走完 B 共 6 步，变成 `None`，跳到 `headA` 继续 `4 → 1 → 8`，第 8 步也踩到 8。

两边都是 8 步，同时停在同一个节点，`a != b` 不成立，循环退出，返回 8。

验算一下步数：a 走了「A 独有 2 个 + 公共 3 个」+「B 独有 3 个」= 8；b 走了「B 独有 3 个 + 公共 3 个」+「A 独有 2 个」= 8，正好一个 $a+b+c$。

再看无交集的情况：$A=[1,2,3]$、$B=[4,5]$。a 走 3 步到头跳 B 再走 2 步共 5 步变 `None`；b 走 2 步到头跳 A 再走 3 步也 5 步变 `None`——两人同时为 `None`，相等，返回 `None`。

# [206. 反转链表](https://leetcode.cn/problems/reverse-linked-list/description/?envType=study-plan-v2&envId=top-100-liked)

三个指针从头往后撸：`prev` 记前一个，`cur` 是当前，改指针前先把 `next` 存下来。

```python
def reverseList(head):
    prev, cur = None, head
    while cur:
        nxt = cur.next      # 先保存，否则改完就找不到了
        cur.next = prev     # 掉头指向前一个
        prev = cur          # prev 前移
        cur = nxt           # cur 前移
    return prev             # prev 最后停在原链表尾，即新头
```

顺序不能颠倒：`cur.next = prev` 一执行，原来的后继就丢了，所以必须先把 `nxt` 存起来。

循环结束时 `cur` 是 `None`，`prev` 才是新的头节点，返回它。

时间 $O(n)$ 一遍扫完，空间 $O(1)$。递归写法也能做（`head.next.next = head`），但深链表会爆栈，面试首选迭代。

# [234. 回文链表](https://leetcode.cn/problems/palindrome-linked-list/)

快慢指针找中点 → 反转后半段 → 两段依次比较。

```python
def isPalindrome(head):
    slow = fast = head
    while fast and fast.next:          # 快指针走两步，慢指针一步
        slow = slow.next
        fast = fast.next.next
    # slow 落在中点（奇数个时就是正中那个）

    prev, cur = None, slow             # 反转后半段
    while cur:
        nxt = cur.next
        cur.next = prev
        prev, cur = cur, nxt

    p, q = head, prev                  # prev 是后半段（已反转）的头
    while q:                           # 后半段走完就停
        if p.val != q.val:
            return False
        p, q = p.next, q.next
    return True
```

`while q` 而不是 `while p and q`，因为奇数长度时前半段比后半段多一个（正中间那个），它不用参与比较。

为什么反转后半段就能比：回文从两端往中间读一样，后半段倒过来就变成和前半段同向，逐位比 `val` 即可。

时间 $O(n)$，空间 $O(1)$。想保持链表原样的话，比较完再反转一次接回去。

最省事的写法是把值全塞进数组再双指针比，但那是 $O(n)$ 空间，面试要的是上面这个。

# [141. 环形链表](https://leetcode.cn/problems/linked-list-cycle/)
快慢指针（Floyd 判圈）：慢的走一步、快的走两步，有环必相遇。

```python
def hasCycle(head):
    slow = fast = head
    while fast and fast.next:      # 快的能走两步才继续
        slow = slow.next
        fast = fast.next.next
        if slow is fast:
            return True
    return False
```

为什么一定相遇：进了环以后，快指针每轮比慢的多走 1 步，两者距离每次缩短一格，环是有限长的，所以迟早重合。

`while fast and fast.next` 两个条件缺一不可，少判一个，`fast.next.next` 在尾节点就会报错。

时间 $O(n)$（慢指针走不到一圈就会被追上），空间 $O(1)$。

要返回入环点的 142 题，在相遇后把其中一个指针拨回头，然后两人都一次走一步，再次相遇的位置就是入口。

# [142. 环形链表 II](https://leetcode.cn/problems/linked-list-cycle-ii/)
先用快慢指针找到相遇点，然后**把一个指针拨回头节点，两人都改走一步**，再次相遇处就是入环点。

```python
def detectCycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow is fast:              # 第一次相遇
            p = head
            while p is not slow:      # 一个从头走，一个从相遇点走
                p = p.next
                slow = slow.next
            return p                  # 第二次相遇 = 入环点
    return None
```

为什么这样能找到入口：设头到入口 $a$ 步、入口到相遇点 $b$ 步、环长 $L$。相遇时慢的走了 $a+b$，快的走了 $a+b+kL$，而快的是慢的两倍，所以 $a+b=kL$，即 $a=kL-b$。

也就是「从头走 $a$ 步」和「从相遇点绕回去走 $a$ 步」会落在同一个节点，那就是入口。

时间 $O(n)$、空间 $O(1)$，不用哈希表也不用改链表。

# [21.合并两个有序链表](https://leetcode.cn/problems/merge-two-sorted-lists/description/?envType=study-plan-v2&envId=top-100-liked)

哨兵节点 + 双指针，剩下的直接接上。

```python
def mergeTwoLists(list1, list2):
    dummy = tail = ListNode()          # 哨兵，省掉头节点的特判
    while list1 and list2:
        if list1.val <= list2.val:
            tail.next = list1
            list1 = list1.next
        else:
            tail.next = list2
            list2 = list2.next
        tail = tail.next
    tail.next = list1 or list2         # 谁先空，另一个整段接上
    return dummy.next
```

用 `dummy` 是为了不用判断“第一个节点该谁当”，否则每插一个都要看 `head` 是否为空。

循环结束时必定有一条链已经走完，剩下的部分本身就是有序的，直接挂到 `tail` 后面即可，不用再逐个搬。

`list1 or list2` 是 Python 的短路写法，非 None 的那个被返回。

时间 $O(m+n)$，空间 $O(1)$（只动了指针，没新建节点）。

`<=` 而不是 `<`，这样相等时先取 list1 的节点，两个原链表的相对顺序得以保持，是稳定合并。

# 2. [两数相加](https://leetcode.cn/problems/add-two-numbers/description/?envType=study-plan-v2&envId=top-100-liked)

逆序存正好是**从个位开始**，于是就能像手算竖式那样一位一位加、把进位往左传。

```python
def addTwoNumbers(l1, l2):
    dummy = tail = ListNode()
    carry = 0
    while l1 or l2 or carry:           # carry 也要进循环条件
        s = carry
        if l1:
            s += l1.val
            l1 = l1.next
        if l2:
            s += l2.val
            l2 = l2.next
        carry, digit = divmod(s, 10)   # 商是进位，余数是本位
        tail.next = ListNode(digit)
        tail = tail.next
    return dummy.next
```

`divmod(s, 10)` 一次拿到进位和本位，比写两行 `%` 和 `//` 干净。

循环条件里带 `carry` 是关键：`99 + 1` 最后会多出一位 `1`，如果只判断 `l1 or l2`，这个最高位进位就丢了。

两条链长度不同时用 `if l1:` / `if l2:` 各自判空，短的走完后自动按 0 处理。

时间 $O(\max(m,n))$，空间 $O(\max(m,n)+1)$（结果链表本身）。


# [19. 删除链表的倒数第 N 个结点](https://leetcode.cn/problems/remove-nth-node-from-end-of-list/description/?envType=study-plan-v2&envId=top-100-liked)

快慢指针拉开 **n 步的间距**，两人一起走，快的到头时慢的正好停在待删节点的前一个。

```python
def removeNthFromEnd(head, n):
    dummy = ListNode(0, head)       # 哨兵，方便删头节点
    fast = slow = dummy

    for _ in range(n):              # 快指针先走 n 步
        fast = fast.next

    while fast.next:                # 一起走到快指针到最后一个节点
        fast = fast.next
        slow = slow.next

    slow.next = slow.next.next      # 跳过待删节点
    return dummy.next
```

两个都从 `dummy` 出发而不是 `head`，是为了让 `slow` 最终落在**前驱**上，这样才改得动 `slow.next`。

没有哨兵的话，删的是头节点时要单独处理返回值，加个假头就统一了。

时间 $O(L)$ 一趟扫完，空间 $O(1)$。

# [24. 两两交换链表中的节点](https://leetcode.cn/problems/swap-nodes-in-pairs/description/?envType=study-plan-v2&envId=top-100-liked)

用哨兵 + 三个指针，每次把 `prev` 后面的**两个节点**互换。

```python
def swapPairs(head):
    dummy = prev = ListNode(0, head)
    while prev.next and prev.next.next:
        a = prev.next          # 第一个
        b = a.next             # 第二个
        prev.next = b          # 让前驱直接指向 b
        a.next = b.next        # a 跳过 b，接上后面的链
        b.next = a             # b 反过来指向 a
        prev = a               # prev 前移两格，落到这一对的尾巴
    return dummy.next
```

改指针的顺序不能乱：先把 `a` 的后续指针修好（`a.next = b.next`），再让 `b.next = a`，否则 `b.next` 一改，`b.next` 原来的值就丢了。

循环条件两个都要判：剩单数个节点时 `prev.next.next` 是 `None`，最后一对就不用动了，直接留在原位。

`prev` 每次前进到 `a`（这一对交换后的尾巴），下一轮就从它的后面接着换。

时间 $O(n)$，空间 $O(1)$，全程只改指针不改值。


# [25. K 个一组翻转链表](https://leetcode.cn/problems/reverse-nodes-in-k-group/description/?envType=study-plan-v2&envId=top-100-liked)

先探路确认这一组够 k 个，够才翻；翻转时把 `prev` 初始化成下一组的头，尾部就自动接好了。

```python
def reverseKGroup(head, k):
    dummy = ListNode(0, head)
    pre = dummy

    while True:
        end = pre
        for _ in range(k):            # 探路：找本组最后一个
            end = end.next
            if not end:
                return dummy.next

        nxt = end.next                # 下一组起点
        start = pre.next              # 本组原来的头，翻转后变尾
        p, c = nxt, start
        while c is not nxt:           # 组内翻转，p 从下一组起跳
            c.next, p, c = p, c, c.next

        pre.next, pre = end, start    # 接好本组，pre 移到新尾
```

两个小技巧：`prev` 从 `group_next` 起跳，反转完最后一个节点自然指向下一组，省一次拼接；用 `tail = group_prev.next` 提前记住反转前的头（反转后变尾），下一轮的 `group_prev` 就是它。

`return` 放在探路失败时，直接返回 `dummy.next`，剩余不足 k 个的节点就没被碰过。

时间 $O(n)$，每个节点只被访问常数次；空间 $O(1)$，递归版是 $O(n/k)$ 栈。

# [138. 随机链表的复制](https://leetcode.cn/problems/copy-list-with-random-pointer/)

最简单的做法是建一张**旧节点 → 新节点**的字典：第一遍只复制节点本身，第二遍再按字典把 `next` 和 `random` 接上；关键是让 `None` 也映射到 `None`，这样空指针就不用特判。

```python
def copyRandomList(head):
    if not head:
        return None
    m = {None: None}          # 空指针也映射，省掉判空
    c = head
    while c:
        m[c] = Node(c.val)
        c = c.next

    c = head
    while c:
        m[c].next = m[c.next]
        m[c].random = m[c.random]
        c = c.next
    return m[head]
```

时间 $O(n)$、空间 $O(n)$。如果想省掉字典，可以用“把新节点插到旧节点后面”的三步法做到 $O(1)$ 空间，但代码长、容易写错，面试时先说字典版通常就够了。
# [148. 排序链表](https://leetcode.cn/problems/sort-list/description/?envType=study-plan-v2&envId=top-100-liked)

思路：链表没法像数组那样随机访问，所以用**归并排序**——先找到中点把链表断成两半，各自递归排序，再把两个有序链表合并。
```python
class Solution:
    def sortList(self, head):
        if not head or not head.next:
            return head

        def merge(a, b):
            d = ListNode(0)
            t = d
            while a and b:
                if a.val <= b.val:
                    t.next, a = a, a.next
                else:
                    t.next, b = b, b.next
                t = t.next
            t.next = a or b
            return d.next

        slow, fast = head, head.next
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next

        mid = slow.next
        slow.next = None
        return merge(self.sortList(head), self.sortList(mid))
```


# [23. 合并 K 个升序链表](https://leetcode.cn/problems/merge-k-sorted-lists/)

有两条常见思路：**用最小堆**每次取 K 条链中最小的头节点，或者**分治两两合并**。堆版本代码最短，也更直接；面试常写这个版本。

```python
import heapq

class Solution:
    def mergeKLists(self, lists):
        h = [(n.val, i, n) for i, n in enumerate(lists) if n]
        heapq.heapify(h)

        d = t = ListNode(0)
        while h:
            _, i, n = heapq.heappop(h)
            t.next = n
            t = t.next
            if n.next:
                heapq.heappush(h, (n.next.val, i, n.next))
        return d.next
```

# [146. LRU 缓存](https://leetcode.cn/problems/lru-cache/)

```python
from collections import OrderedDict

class LRUCache:
    def __init__(self, capacity: int):
        self.d = OrderedDict()
        self.n = capacity

    def get(self, key: int) -> int:
        if key not in self.d:
            return -1
        self.d.move_to_end(key)          # 访问即刷新
        return self.d[key]

    def put(self, key: int, value: int) -> None:
        self.d[key] = value
        self.d.move_to_end(key)          # 新建/更新都移到队尾
        if len(self.d) > self.n:
            self.d.popitem(last=False)   # 弹出队头最旧的
```

`OrderedDict` 尾部表示**最近使用**，头部表示最久未使用；`move_to_end` 负责更新位置，`popitem(last=False)` 负责淘汰。注意 `get` 也要移动，否则顺序不会刷新。
