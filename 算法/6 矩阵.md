# [73. 矩阵置零](https://leetcode.cn/problems/set-matrix-zeroes/)
做法是**拿第一行和第一列当草稿纸**：先在上面记下哪些行、哪些列要清零，记完了再统一清。

最直白的笨办法是再开一个同样大的数组记标记，但题目要原地，所以**借矩阵自己的第一行、第一列**来存。

```python
def setZeroes(matrix):
    m, n = len(matrix), len(matrix[0])
    row0 = any(v == 0 for v in matrix[0])      # 判断第一行带 0 吗
    col0 = any(matrix[i][0] == 0 for i in range(m))

    for i in range(1, m):                      # 第一遍：记标记
        for j in range(1, n):
            if matrix[i][j] == 0:
                matrix[i][0] = 0               # 第 i 行 画个记号
                matrix[0][j] = 0               # 第 j 列 画个记号

    for i in range(1, m):                      # 第二遍：按记号清零
        for j in range(1, n):
            if matrix[i][0] == 0 or matrix[0][j] == 0:
                matrix[i][j] = 0

    if row0:                                   # 第三遍：补第一行
        for j in range(n):
            matrix[0][j] = 0
    if col0:                                   # 补第一列
        for i in range(m):
            matrix[i][0] = 0
```

打个比方：草稿纸就是第一行和第一列，上面写“这行要擦掉”。所以扫的时候要**跳过第一行第一列**（循环从 1 开始），不然草稿纸自己被擦了，记号就没了。

`row0`、`col0` 两个布尔值是给第一行、第一列自己留的备忘，因为它们既当草稿纸又当数据，自己记不下自己。

第一行和第一列必须放到**最后**处理，理由同上：先清就把标记清没了。


# [54. 螺旋矩阵](https://leetcode.cn/problems/spiral-matrix/)
标准解法是**四条边界轮流收缩**：上、右、下、左各走一条边，走完就把那条边往里推一格。

```python
def spiralOrder(matrix):
    if not matrix:
        return []
    top, bottom = 0, len(matrix) - 1
    left, right = 0, len(matrix[0]) - 1
    res = []

    while top <= bottom and left <= right:
        for j in range(left, right + 1):        # 左 → 右，走上边
            res.append(matrix[top][j])
        top += 1

        for i in range(top, bottom + 1):        # 上 → 下，走右边
            res.append(matrix[i][right])
        right -= 1

        if top <= bottom:                       # 还有行才走下边
            for j in range(right, left - 1, -1):
                res.append(matrix[bottom][j])
            bottom -= 1

        if left <= right:                       # 还有列才走左边
            for i in range(bottom, top - 1, -1):
                res.append(matrix[i][left])
            left += 1

    return res
```

关键是那两个 `if`：剩下单行时，走完上边 `top` 就超过 `bottom` 了，不加判断会**重复**再走一遍下边；单列同理。

循环条件是 `top <= bottom and left <= right`，任一边界交叉就说明扫完了。

每个元素恰好访问一次，时间 $O(mn)$，额外空间 $O(1)$（不算返回值）。

  

# [48. 旋转图像](https://leetcode.cn/problems/rotate-image/)

顺时针 90° 可以拆成两步：**先沿主对角线转置，再把每一行左右翻转**。

```python
def rotate(matrix):
    n = len(matrix)

    for i in range(n):                 # 1. 转置
        for j in range(i + 1, n):      # 只走上三角，对着换一次就够
            matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]

    for row in matrix:                 # 2. 每行反转
        row.reverse()
```

`j` 从 `i + 1` 开始，是为了不重复交换、也不碰对角线（自己换自己没有意义）。

为什么这两步等于旋转：转置把 $(i,j)$ 搬到 $(j,i)$，相当于沿对角线翻折；再左右翻转一次，两次翻折叠加正好是**顺**时针 90°。逆时针的话就是把第二步换掉——先上下翻转再转置，顺序也反过来。

空间 $O(1)$，原地完成；时间 $O(n^2)$，每个格子都要动。

如果要求不许用这两步，纯手动版是四个角一起轮换：`matrix[i][j] → matrix[j][n-1-i] → ...`，写法更绕但同样原地。

# [240. 搜索二维矩阵 II](https://leetcode.cn/problems/search-a-2d-matrix-ii/)
从**右上角**出发，每次比较能砍掉一整行或一整列。

```python
def searchMatrix(matrix, target):
    if not matrix or not matrix[0]:
        return False
    i, j = 0, len(matrix[0]) - 1        # 右上角
    while i < len(matrix) and j >= 0:
        if matrix[i][j] == target:
            return True
        elif matrix[i][j] > target:
            j -= 1                      # 整列下面都更大，这一列废掉
        else:
            i += 1                      # 整行左边都更小，这一行废掉
    return False
```

选右上角是因为它同时是**本行最大、本列最小**：比 target 大，说明这一列往下全大，往左走；比 target 小，说明这一行往左全小，往下走。

所以每走一步必然排除一条，最多走 $m+n$ 步，时间 $O(m+n)$、空间 $O(1)$。

左下角同理，也可以；左上角和右下角不行，那里两个方向都同向变化，没法判断该往哪走。

注意这题和 74 题不同：74 题整体拉直有序可以二分 $O(\log mn)$，这题只保证行、列各自有序，只能这么走。
