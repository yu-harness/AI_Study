## 🔴 高风险 (1项)

**[管辖不利]** 第九条约定"由甲方所在地人民法院管辖"

风险：委托方为乙方，合同履行地、被告所在地均在乙方，但发生争议时需到甲方所在地人民法院起诉。这会增加乙方的诉讼成本（差旅费、律师费等），且甲方所在地法院可能存在地方保护倾向，不利于乙方维权。

建议：修改为：
- 方案A：改为"由乙方所在地人民法院管辖"
- 方案B：改为仲裁条款——"凡因本合同产生的或与本合同有关的任何争议，双方应协商解决；协商不成的，提交XX仲裁委员会按照该会现行仲裁规则进行仲裁。仲裁裁决是终局的，对双方均有约束力"

## 🟡 中风险 (3项)

**[对方违约金惩罚不足]** 第七条约定"甲方逾期付款，每日按应付金额的0.01%支付违约金"

- 违约主体：甲方（对方）→ 对方违约时需向委托方(乙方)支付违约金
- 风险：每日0.01%换算年化约3.65%，与当前LPR（3.45%）持平，对甲方几乎没有额外约束力。甲方可能将逾期付款当作"低成本融资"，故意拖延付款，乙方缺少有效的制约手段。
- 建议：将甲方逾期付款违约金提高至每日0.05%（年化约18.25%），或约定固定违约金："甲方逾期付款超过30日的，应一次性向乙方支付合同总金额20%的违约金"

📖 依据：通用规则

**[付款条件模糊]** 第三条约定"甲方应在乙方交付成果后30个工作日内支付全部款项"

风险："交付成果"这一表述过于笼统。合同第一条仅描述了项目范围但未定义交付物清单和验收标准。如果甲方以"成果不满意"为由拒付，乙方将面临举证困难——甲方的"不满意"是主观判断，无法客观衡量。

建议：将第三条细化为：
```
## 第三条 交付与验收
1. 交付物清单：乙方应交付以下成果：
   - 前端源代码（含React组件库、样式文件）
   - 后端源代码（含API接口文档）
   - 数据库设计文档
   - 部署运维说明
2. 验收标准：交付物应符合附件一《技术规格说明书》的功能要求
3. 验收期限：甲方应在收到全部交付物后10个工作日内完成验收；逾期未提出书面异议的，视为验收合格
4. 付款安排：验收合格后30个工作日内，甲方向乙方支付全部款项
```

📖 依据：通用规则

**[知识产权归属明确但未处理背景IP授权]** 第五条约定"除乙方原有的通用代码库外，本项目成果的知识产权归甲方所有"

风险：该条款虽然保护了乙方的背景IP，但未明确：(1)乙方背景IP的具体范围清单；(2)甲方对乙方背景IP是否有使用许可。若甲方未来需独立维护代码，可能面临无权使用乙方通用代码库的风险。

建议：(1)以附件形式列出乙方背景IP的具体清单；(2)增加条款："乙方授予甲方对其背景IP的永久、免费、不可撤销的使用许可，该许可仅限于本合同项目的运行、维护和二次开发"

📖 依据：服务合同专项规则

## ℹ️ 提示 (1项)

**[缺少保密条款]** 合同未约定保密义务

风险：双方在合作过程中不可避免地会交换商业秘密信息（如甲方业务数据、乙方技术方案等）。合同缺乏保密约束，任一方可能泄露对方敏感信息而无须承担违约责任。

建议：增加保密条款：
```
## 第X条 保密义务
1. 任何一方对于因签署或履行本合同而获知的对方的商业秘密（包括但不限于技术方案、客户信息、财务数据、业务模式等）负有保密义务，未经对方书面同意，不得向任何第三方披露
2. 保密期限自本合同签订之日起至合同终止后3年止
3. 违反保密义务的一方应赔偿对方因此遭受的全部损失
```

📖 依据：通用规则
