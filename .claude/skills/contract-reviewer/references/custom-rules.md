# 自定义审查规则

用户可以在此文件中定义额外的审查规则，作为内置规则的补充或覆盖。自定义规则具有**最高优先级**。

---

## 使用方式

1. 按照下方模板，在本文件中添加自定义规则
2. 保存文件后，下一次合同审查将自动加载这些规则
3. 不需要的规则可以删除，或将整个文件清空以仅使用内置规则

---

## 规则模板

每条规则由以下字段组成：

```markdown
### 规则：[规则名称]

- **审查维度**：[一句话描述这条规则检查什么，如：是否约定了数据安全条款]
- **关键词**：["关键词1", "关键词2", "关键词3"]
- **检查内容**：[详细说明检查逻辑]
- **风险等级**：🔴高风险 / 🟡中风险 / ℹ️提示
- **输出示例**：
  ```
  [风险标签] 原文引用或说明
  风险：(描述具体风险)
  建议：(给出可操作的修改建议)
  ```
```

---

## 注意事项

1. **关键词字段**用于在合同中搜索相关条款位置，请使用中文关键词
2. **风险等级**必须从 🔴高风险 / 🟡中风险 / ℹ️提示 中选择
3. 如果你的自定义规则与内置规则审查同一维度（如都在审查"违约金"），你的规则中的阈值/标准将覆盖内置规则
4. 每个规则的结果将根据其风险等级，被归入报告的对应板块（🔴/🟡/ℹ️）
5. 审核报告中来自自定义规则的风险项，会在建议末尾标注 `📖 依据：自定义规则`
