# 合同审查规则详解

本文档详细定义了合同风险审查的内置规则和判断标准。

## 一、违约金合理性审查

### 审查目标
查找合同中的违约责任条款，判断违约金是否合理。

### ⚠️ 核心原则：主体绑定（必须先执行）

在审查任何违约金条款之前，**必须先回答两个问题**：

1. **这条款约束的是谁的违约行为？** → 我方（委托方）还是对方？
2. **谁在向谁支付违约金？** → 对方→我方，还是我方→对方？

**同一条款中如果同时约束双方（如"任一方逾期，每日按XX支付违约金"），必须拆开分别评估，不得混为一谈。**

> 🚨 **铁律**：我方违约金低 → 对我方有利（好事）；对方违约金低 → 对我方不利（坏事）。**方向反了，结论就全反了。**

---

### 判断标准

#### 第一步：识别违约主体

对每条违约金条款，明确标注违约主体：

| 条款表述示例 | 违约主体 | 委托方=甲方时 | 委托方=乙方时 |
|---|---|---|---|
| "甲方逾期付款，每日按 X% 支付" | 甲方 | **我方** | **对方** |
| "乙方逾期交付，每日按 X% 支付" | 乙方 | **对方** | **我方** |
| "任一方违约，每日按 X% 支付" | 双方 | 需分别评估 | 需分别评估 |

#### 第二步：按违约主体适用不同标准

---

##### 情形 A：条款约束【对方】的违约责任

（对方违约 → 对方需向我方支付违约金）

> 核心逻辑：对方的违约金越低，我方的保障越弱 → 风险越高

| 对方违约金水平 | 对我方影响 | 风险等级 |
|---|---|---|
| 完全未约定对方违约金 | 对方违约零成本，我方毫无保障 | 🔴 高风险 |
| 每日 < 0.03%（年化 < 11%） | 惩罚严重不足，对方可能故意违约 | 🟡 中风险 [对方违约惩罚不足] |
| 每日 0.03%-0.05%（年化 11%-18%） | 基本合理 | ℹ️ 提示（可酌情争取更高） |
| 每日 0.05%-0.1%（年化 18%-36%） | 合理水平 | ✅ 无风险 |
| 每日 > 0.1%（年化 > 36%） | 惩罚力度大，对我方有利；但过高部分法院可能不支持 | ℹ️ 提示（过高部分可能不被支持，但整体对我方有利） |

##### 情形 B：条款约束【我方（委托方）】的违约责任

（我方违约 → 我方需向对方支付违约金）

> 核心逻辑：我方的违约金越低，我方的风险敞口越小 → 对我方越有利

| 我方违约金水平 | 对我方影响 | 风险等级 |
|---|---|---|
| 完全未约定我方违约金 | 我方违约零成本，对我方极为有利 | 🟢 对我方有利（不报告或归为有利项） |
| 每日 < 0.03%（年化 < 11%） | 违约成本很低，对我方有利 | 🟢 对我方有利 / 不报告 |
| 每日 0.03%-0.05%（年化 11%-18%） | 可接受范围 | ℹ️ 提示（可关注但无需恐慌） |
| 每日 0.05%-0.1%（年化 18%-36%） | 违约成本偏高，值得关注 | 🟡 中风险 [我方违约成本过高] |
| 每日 > 0.1%（年化 > 36%） | 违约成本极高，极不公平 | 🔴 高风险 [我方违约成本极高] |
| 每日 > 0.3%（年化 > 100%） | 明显不公，可能触犯《民法典》第585条 | 🔴 高风险 [可能构成显失公平] |

---

### 参考基准
- 每日 **0.05%**（年化约 18.25%）= 司法实践中的常见合理基准线
- 当前 **LPR**（贷款市场报价利率）≈ 3.45%，对方违约金年化不应低于 LPR 的 2-3 倍
- 《民法典》第 585 条：约定的违约金过分高于造成的损失的，当事人可以请求人民法院或者仲裁机构予以适当减少

---

### 输出示例

**示例 1：对方违约金过低（委托方=乙方）**
```
[对方违约金惩罚不足] 第七条约定"甲方逾期付款，每日按应付金额的0.01%支付违约金"
违约主体：甲方（对方）
风险：年化仅约3.65%，与LPR持平，对甲方几乎没有额外约束力。
      甲方可能将逾期付款当作"低成本融资"，故意拖延付款。
建议：将甲方逾期付款违约金提高至每日0.05%（年化约18.25%），
      或约定固定违约金"甲方逾期付款超过30日的，应一次性支付合同总金额20%的违约金"
```

**示例 2：我方违约金过低（委托方=乙方）→ 对我方有利，不报风险**
```
委托方=乙方，条款"乙方逾期交付，每日按0.01%支付违约金"
→ 这对我方(乙方)有利——即使延期交付，违约金成本也很低
→ 不报告为风险，可归为 🟢 对我方有利
```

**示例 3：我方违约金过高（委托方=甲方）**
```
[我方违约成本过高] 第五条约定"甲方逾期付款，每日按合同金额的0.3%支付违约金"
违约主体：甲方（我方/委托方）
风险：年化约109.5%，远超司法实践合理水平。一旦我方因故逾期付款，
      将面临巨额违约金索赔。该条款可能构成《民法典》第585条规定的
      "违约金过分高于造成的损失"，虽可请求法院调减，但诉讼成本高。
建议：争取将违约金降至每日0.05%（年化约18.25%），或约定违约金
      上限（如不超过合同总金额的20%）
```

## 二、管辖法院审查

### 审查目标
查找争议解决条款，判断管辖法院对委托方是否有利。

### 关键词
"管辖法院"、"争议解决"、"仲裁"、"起诉"、"诉讼"、仲裁委员会"

### 判断标准
- **有利**：约定"委托方所在地人民法院管辖"或"双方协商/仲裁"
- **不利**：约定"对方所在地人民法院管辖"
- **中性**：约定"合同签订地/履行地法院管辖"（需结合具体情况）

### 风险定级
| 情况 | 等级 |
|------|------|
| 管辖法院为对方所在地 | 🔴 高风险 |
| 管辖法院为中立第三方 | 🟡 中风险 |
| 未约定管辖法院 | 🟡 中风险（默认由被告所在地或合同履行地管辖） |
| 管辖法院为委托方所在地 | ✅ 无风险 |

### 输出示例
```
[管辖不利] 第九条约定"由甲方所在地人民法院管辖"
风险：若委托方为乙方，发生争议时需到甲方所在地起诉，增加维权成本和诉讼不便
建议：改为"由乙方所在地人民法院管辖"，或改为仲裁条款"双方协商不成，提交XX仲裁委员会仲裁"
```

## 三、保密条款审查

### 审查目标
检查合同是否包含保密条款或保密协议相关内容。

### 关键词
"保密"、"机密"、"商业秘密"、"NDA"、"保密义务"、"泄密"、"保密信息"、"竞业"

### 判断标准
- **完善**：明确约定保密范围、保密期限和违约责任
- **简单**：提及保密但缺乏具体范围和期限
- **缺失**：未涉及任何保密内容

### 风险定级
| 情况 | 等级 |
|------|------|
| 完全无保密条款 | ℹ️ 提示（建议补充） |
| 有保密条款但不完整（缺范围或期限） | ℹ️ 提示 |
| 保密条款完善 | ✅ 无风险 |

### 输出示例
```
[缺少保密条款] 合同未约定保密义务
风险：合同履行过程中可能涉及商业秘密交换，无保密约束可能造成信息泄露
建议：增加保密条款，明确：(1)保密信息范围 (2)保密期限（如合同终止后3年）(3)违约责任
```

## 四、付款条件审查

### 审查目标
检查付款条款中的触发条件和验收标准是否明确。

### 关键词
"付款"、"支付"、"交付"、"验收"、"完成后"、"到账"、"到款"、"支付方式"、"结算"

### 判断标准
- **明确**：有具体的交付物清单、验收标准、验收期限和付款时间节点
- **模糊**：使用"验收合格后"、"交付完成后"等笼统表述但无具体标准
- **缺失**：未约定付款条件

### 风险定级
| 情况 | 等级 |
|------|------|
| 付款条件缺失或完全模糊 | 🔴 高风险 |
| 付款条件存在模糊之处（如"交付后"无具体验收标准） | 🟡 中风险 |
| 付款条件明确 | ✅ 无风险 |

### 输出示例
```
[付款条件模糊] 第三条约定"乙方交付成果后30个工作日内支付"
风险："交付成果"未明确验收标准，何种情况算"完成交付"不清晰，易产生争议
建议：明确：(1)交付物清单 (2)验收标准 (3)验收期限（如收到交付物后5个工作日内验收）
```

## 通用输出规范

### 建议类型优先级
1. **条款修改** > **条款增补** > **提示注意**

### 风险等级颜色代码
- 🔴 高风险：必须修改，否则可能造成重大损失
- 🟡 中风险：建议修改，存在潜在争议
- ℹ️ 提示：仅供参考，可酌情处理
