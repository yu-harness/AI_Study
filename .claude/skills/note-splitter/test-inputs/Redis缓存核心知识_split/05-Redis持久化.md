# 🎯 Redis 持久化：RDB vs AOF

**这个知识点要回答：Redis 的两种持久化方式各有什么优缺点？如何选择？**

---

## ✍️ 自测

① RDB 持久化的原理是什么？优点和缺点分别是什么？


② AOF 持久化的原理是什么？优点和缺点分别是什么？


③ 如果同时开启了 RDB 和 AOF，Redis 重启时用哪个恢复？为什么？


---

## ✅ 参考答案

① **RDB（快照持久化）**：定期生成**全量数据快照**保存到磁盘。**优点**：文件紧凑，适合备份和灾难恢复；加载速度快。**缺点**：定期快照，可能丢数据（两次快照间隔内的数据）

② **AOF（追加日志）**：记录每次**写操作**到日志文件。**优点**：更安全（可配置 everysec 每秒同步，最多丢1秒数据）。**缺点**：文件比 RDB 大；恢复速度比 RDB 慢

③ 同时开启时，Redis 重启**优先用 AOF 恢复**。因为 AOF 数据更完整，丢失数据更少
