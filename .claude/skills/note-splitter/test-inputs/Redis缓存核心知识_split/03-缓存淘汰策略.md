# 🎯 缓存淘汰策略

**这个知识点要回答：Redis 内存满了怎么办？有哪些淘汰策略？怎么选？**

---

## ✍️ 自测

① Redis 有哪些淘汰策略？分别描述它们的行为。


② 生产环境最推荐使用哪种策略？为什么？


③ 如果业务要求绝对不能丢 key，应该用哪种策略？


---

## ✅ 参考答案

① 六种策略：
   - **noeviction**（默认）：不淘汰，直接返回错误
   - **allkeys-lru**：从所有 key 中淘汰**最近最少使用**的
   - **allkeys-lfu**：从所有 key 中淘汰**最不常用**的
   - **volatile-lru**：从设置了 TTL 的 key 中淘汰最近最少使用的
   - **volatile-lfu**：从设置了 TTL 的 key 中淘汰最不常用的
   - **volatile-ttl**：从设置了 TTL 的 key 中淘汰即将过期的

② 推荐使用 **`allkeys-lru`**，通常表现最好。因为它对所有 key 一视同仁，淘汰最近最少被访问的 key，大多数业务场景下 LRU 算法效果最优

③ 使用 **noeviction**（默认策略），内存满时不淘汰任何 key，直接返回错误。但这需要业务层做好内存监控，防止写入失败
