# 超参数搜索：Grid / Random / 贝叶斯

## 一句话

**模型参数是训练学出来的，超参数是你选的；搜索就是"怎么用最少的训练次数把超参数选对"。**

学习率、batch size、warmup 比例、LoRA 的 $r$ 与 $\alpha$、weight decay，都属于超参数。

## 三种主流方法

| 方法 | 怎么做 | 组合数 | 适合 |
| --- | --- | --- | --- |
| **Grid Search**（网格） | 每个超参数列几个候选，**笛卡尔积**全跑一遍 | 固定，$k^n$ | 候选少（2–3 个维度、每个 3–5 个值） |
| **Random Search** | 在每个区间里**随机采样**若干组 | 你定次数 | 维度多、只有少数参数真正重要 |
| **Bayesian Optimization** | 用已跑结果建代理模型，**猜下一个最可能有收益的点** | 迭代式，通常 20–50 次 | 每次训练很贵、维度中等 |

关键结论来自 Random Search 的经典实验：**维度超过 3–4 个时，随机搜索比网格更划算**——因为真正影响结果的往往只有一两个参数，网格在无关维度上做了大量重复实验。

## Grid Search 具体怎么跑

以 LoRA 微调的学习率为例，候选 `[5e-5, 8e-5, 1e-4]`：

```text
for lr in [5e-5, 8e-5, 1e-4]:
    for epochs in [2, 3]:
        训练 → 记录验证集 loss / 任务指标
选指标最好的一组，例如 lr=5e-5、epochs=2
```

两个实操要点：

1. **必须固定其余变量**。数据、seed、batch size、训练步数都一样，只改被搜索的那个，否则比出来的差异不知道来自谁。
2. **用验证集选，不用测试集**。测试集只在最后用一次，否则就是拿测试集调参，指标虚高。

## "小规模"是什么意思

全量 Grid Search 的代价是**组合数 × 单次训练时间**。3 个学习率 × 2 个 epoch 数 = 6 次完整训练，14B 模型上可能是几天。所以实践里都做"小规模"：

| 缩减手段 | 做法 | 代价 |
| --- | --- | --- |
| 减步数 | 只跑 200–500 步，比 loss 下降曲线 | 早停点的结论未必适用到收敛 |
| 减数据 | 用 10% 数据子集 | 小数据上最优的 lr 在大数据上可能偏大 |
| 减维度 | 只搜最敏感的一两个（通常是 lr） | 忽略参数间交互 |
| 先粗后细 | 先 `1e-5 / 1e-4 / 1e-3` 定位量级，再在该量级附近细化 | 多一轮实验 |

判断依据不是"loss 最低"，而是**曲线形状**：好的学习率在几百步内 loss 下降最快且不抖；太大的会震荡或 NaN，太小的几乎不降。

## LoRA 场景的特殊之处

| 参数 | 常见范围 | 说明 |
| --- | --- | --- |
| 学习率 | $1\times10^{-4}$ ~ $2\times10^{-4}$ | 比全参微调大一个量级，因为只更新小矩阵 |
| $r$ | 8 / 16 / 32 / 64 | 任务越复杂、数据越多，$r$ 可取大 |
| $\alpha$ | 常取 $2r$ | 与 $r$ 的比值决定更新幅度 |
| epochs | 2–3 | 超过 3 轮在小数据上极易过拟合 |

所以真实项目里通常**只搜学习率**，$r$ 与 $\alpha$ 按经验定。这与"小规模 Grid Search（5e-5、8e-5、1e-4）"这类描述一致——搜索维度只有一个。

## 几个容易踩的坑

**用最终 loss 比较，忽略遗忘**。微调的学习率不是越小越好，也不是 loss 越低越好；学习率过大会让基座能力退化（灾难性遗忘），所以选型要同时看"目标任务指标"和"通用能力是否掉"。

**不同 lr 用了不同 warmup**。warmup 与 lr 强耦合，改 lr 不改 warmup，比较结果不公平。

**只看单次运行**。训练有随机性，至少 2–3 个 seed 取平均，否则差异可能是噪声。

**搜索空间设错**。学习率应按**对数**取点（`1e-5、3e-5、1e-4、3e-4`），而不是线性（`1e-5、2e-5、3e-5`）——量级差异远大于同量级内的细微差别。

## 什么时候根本不用搜

- 有成熟配方：Llama / Qwen 的官方微调脚本已给出经过验证的 lr 与 warmup，直接沿用
- 数据量很小：几百条样本时，超参数的影响远小于数据质量
- 只做一次实验：搜索的成本高于收益，先用默认值跑通再谈调优

## 面试可能的问法

**Q：为什么说随机搜索常常优于网格搜索？**
因为高维空间里多数超参数不敏感，网格会在无关维度上重复实验；随机采样让每个维度被"独立探索"更多次，有限预算下更可能碰到好的组合。

**Q：微调时学习率怎么定？**
先按任务类型定量级（LoRA 约 $10^{-4}$、全参约 $10^{-5}$），再用小规模实验在量级内取 2–3 个点比较曲线，同时监控通用能力是否退化。

**Q：只在 200 步上比出来的 lr 能直接用吗？**
可以做初筛，但要用完整训练复核一次。短跑最优的 lr 往往偏大（早期下降快），长跑时可能震荡。
