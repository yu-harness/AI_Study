Transformer 升级之路：2、博采众长的旋转式位置编码

上一篇文章推导了原始的 Sinusoidal 位置编码，结论是：它可以看作一种「想做相对位置编码的绝对位置编码」。绝对位置编码实现简单、计算快；相对位置编码直接表达词与词的距离，更符合直觉，性能通常也更好。如果能用绝对位置编码的写法，拿到相对位置的性质，两边的好处就都占了。Sinusoidal 接近这个目标，但没做到位。

本文介绍 RoFormer 模型，它的核心改动是把位置编码换成「旋转式位置编码」（Rotary Position Embedding，RoPE）。

一句话说清它特别在哪：用绝对位置编码的写法，拿到了相对位置编码的效果。也正因为不依赖注意力矩阵，它是目前唯一能用到线性 Attention 上的相对位置编码。

RoFormer：https://github.com/ZhuiyiTechnology/roformer

基本思路

出发点是「用绝对位置编码的方式实现相对位置编码」。理论上优雅，实践上也有用：它是目前唯一能用到线性 Attention 的相对位置编码。

整节分三步：打位置标签、要求内积只依赖位置差、补一个初始条件。

第一步，给向量打上位置标签

为了达到这个目的，我们假设通过下述运算来给 𝐪,𝐤\boldsymbol{q},\boldsymbol{k} 添加绝对位置信息：

𝐪̃m=f(𝐪,m),𝐤̃n=f(𝐤,n) \tilde{\boldsymbol{q}}_m=f(\boldsymbol{q},m),\qquad \tilde{\boldsymbol{k}}_n=f(\boldsymbol{k},n) \tag{1}

逐项读一遍：

  • 𝐪̃m\tilde{\boldsymbol{q}}_m：位置 mm 上的查询向量，波浪号表示已经打过位置标签
  • ff：待定函数，输入「向量 + 位置编号」，输出「带位置信息的向量」
  • 𝐪\boldsymbol{q} 与 𝐤\boldsymbol{k} 共用同一个 ff，只是喂进去的位置不同

这一步是在设未知数：还没有决定位置信息怎么加，只假设存在这样一个操作。至于 ff 长什么样，交给式 (2) 的约束反推。

第二步，要求内积只依赖位置差

经过这一步，𝐪\boldsymbol{q}、𝐤\boldsymbol{k} 各自带上了绝对位置。Attention 的核心运算是内积，我们希望内积的结果带相对位置信息，于是进一步假设存在恒等关系：

⟨f(𝐪,m),f(𝐤,n)⟩=g(𝐪,𝐤,m−n) \langle f(\boldsymbol{q},m),f(\boldsymbol{k},n)\rangle=g(\boldsymbol{q},\boldsymbol{k},m-n) \tag{2}

为什么要把要求写成这个样子：

  • Attention 的打分就是 𝐪⋅𝐤\boldsymbol{q}\cdot\boldsymbol{k}，位置信息只有进到内积里，才能影响注意力权重。所以约束必须下在内积上。
  • 式 (1) 只保证每个向量各自带了绝对位置。要让模型看到的是「两个 token 相隔多远」，就得在内积里把各自的绝对编号消掉，只留差值。
  • 写成 g(𝐪,𝐤,m−n)g(\boldsymbol{q},\boldsymbol{k},m-n) 正是这个意思：内积的结果里，位置只以 m−nm-n 这一个数出现，mm、nn 单独出现的情况被排除。
  • 注意 m−nm-n 仍然在，相对位置没丢。丢掉的只是「谁在第 3 位、谁在第 7 位」这种编号，保留的是「它们隔了 4 位」。
  • 附带好处是平移不变：整句话往后挪几位，注意力结果不变；长度外推也更有依据。

这个式子是约束，不负责构造。它不告诉我们 ff 长什么样，只是把所有「内积里还残留绝对位置」的 ff 排除掉，剩下的才有资格进入下一步求解。

第三步，补一个初始条件把解定下来

所以我们要求出该恒等式的一个（尽可能简单的）解。求解过程还需要一些初始条件，显然我们可以合理地设 f(𝐪,0)=𝐪f(\boldsymbol{q},0)=\boldsymbol{q} 和 f(𝐤,0)=𝐤f(\boldsymbol{k},0)=\boldsymbol{k}。

补充几点读法：

  • 为什么是「一个解」：式 (2) 的未知量是函数 ff，满足条件的 ff 有一整族。给所有位置统一加一个固定旋转角，等式仍然成立。所以只能从这一族里挑一个，标准是尽量简单。
  • 为什么要初始条件：函数方程的通解带一个自由常数，就像解微分方程需要初值才能定下一条曲线。这里缺的正是「整体相位偏移多少」。
  • f(𝐪,0)=𝐪f(\boldsymbol{q},0)=\boldsymbol{q} 的含义：位置 0 等于不加任何东西，第 0 个 token 的向量保持原样。
  • 为什么可以这样设：它只是选了一个参照点。所有位置一起偏移，内积只依赖 m−nm-n，相对性质不变。不加这个条件，相当于给所有 token 的表示统一乘一个固定旋转，输入分布被整体扭转，训练还得重新适应。

补上初始条件后，下一节能推出唯一形状 f(𝐪,m)=𝐪eimθf(\boldsymbol{q},m)=\boldsymbol{q}e^{im\theta}。

求解过程

前置知识：为什么「乘共轭再取实部」等于内积

一、复数就是二维向量。q = (3, 4) 和 q = 3 + 4i 指同一个东西，3 是横向坐标，4 是纵向坐标。

二、内积怎么算。(3, 4) 与 (1, 2) 的内积 = 3×1 + 4×2 = 11，两个坐标分别相乘再相加。

三、用复数乘法算同一个数。取共轭就是把虚部符号反过来：k = 1 + 2i，k* = 1 − 2i。

(3 + 4i)(1 − 2i)
= 3 − 6i + 4i − 8i²
= 3 + 8 − 2i
= 11 − 2i

实部是 11，和第二步算出的内积一样。

四、为什么必须取共轭。不取共轭直接算：

(3 + 4i)(1 + 2i)
= 3 + 6i + 4i + 8i²
= 3 − 8 + 10i
= −5 + 10i

实部变成 −5，即 3×1 − 4×2，和正着的内积差一个符号。原因在于 i² = −1：两个虚部相乘会翻成负数。取共轭把其中一个虚部变号，正好抵消，4×2 就回到 +8。

所以「乘共轭再取实部」就是内积，只是同一个数的两种算法。

式 (2) 左边是 ⟨f(q,m), f(k,n)⟩。这里的 f(q,m) 仍是二维向量，只是被位置处理过，它的内积一样能用上面那套算，于是有 ⟨f(q,m), f(k,n)⟩ = Re[f(q,m)·f(k,n)*]。把式 (2) 左边换成这个写法、右边 g 原样不动，就是式 (3)。

同上一篇思路一样，我们先考虑二维情形，然后借助复数来求解。在复数中有 ⟨𝐪,𝐤⟩=Re⁡[𝐪𝐤*]\langle\boldsymbol{q},\boldsymbol{k}\rangle=\operatorname{Re}\left[\boldsymbol{q}\boldsymbol{k}^{*}\right]，Re⁡[]\operatorname{Re}[\ ] 代表复数的实部，所以我们有

Re⁡[f(𝐪,m)f*(𝐤,n)]=g(𝐪,𝐤,m−n) \operatorname{Re}\left[f(\boldsymbol{q},m)f^{*}(\boldsymbol{k},n)\right]=g(\boldsymbol{q},\boldsymbol{k},m-n) \tag{3}

两个问题分开看。

为什么先看二维：二维向量的旋转只要一个角度，写成复数最省事。𝐪=(a,b)\boldsymbol{q}=(a,b) 写成 a+bia+bi，乘以 eiθe^{i\theta} 就是逆时针转 θ\theta 角，模长不变。式 (2) 要的「保模长 + 可组合」，在复数里就是「乘一个单位复数」。

式 (3) 是怎么来的：复数里内积就是 Re⁡[𝐪𝐤*]\operatorname{Re}[\boldsymbol{q}\boldsymbol{k}^{*}]。设 𝐪=a+bi\boldsymbol{q}=a+bi、𝐤=c+di\boldsymbol{k}=c+di：

𝐪𝐤*=(a+bi)(c−di)=(ac+bd)+(bc−ad)i \boldsymbol{q}\boldsymbol{k}^{*}=(a+bi)(c-di)=(ac+bd)+(bc-ad)i

实部 ac+bdac+bd 正是实数内积，虚部是二维行列式，与内积无关。把 𝐪\boldsymbol{q} 换成 f(𝐪,m)f(\boldsymbol{q},m)、𝐤\boldsymbol{k} 换成 f(𝐤,n)f(\boldsymbol{k},n)，左边就成了 ⟨f(𝐪,m),f(𝐤,n)⟩\langle f(\boldsymbol{q},m),f(\boldsymbol{k},n)\rangle，右边沿用式 (2) 的 gg，于是有了式 (3)。

式 (3) 和式 (2) 是同一个式子，只是换了记号。换成复数的原因是后面要对 f(𝐪,m)f*(𝐤,n)f(\boldsymbol{q},m)f^{*}(\boldsymbol{k},n) 做代数变形，而「模长为 1 的乘法」在复数里只有 eiθe^{i\theta} 这一种形式，等于提前把形状锁定；用矩阵写，要绕一圈才能走到这一步。

从这里开始是推导，跟着走一遍就行。

任何复数都能写成「模长 × 角度」的形式：模长表示这个向量有多长，eiθe^{i\theta} 表示它指向哪个方向。所以先把 ff 设成这个样子。

简单起见，我们假设存在复数 g(𝐪,𝐤,m−n)g(\boldsymbol{q},\boldsymbol{k},m-n)，使得 f(𝐪,m)f*(𝐤,n)=g(𝐪,𝐤,m−n)f(\boldsymbol{q},m)f^{*}(\boldsymbol{k},n)=g(\boldsymbol{q},\boldsymbol{k},m-n)，然后我们用复数的指数形式，设

f(𝐪,m)=Rf(𝐪,m)eiΘf(𝐪,m)f(𝐤,n)=Rf(𝐤,n)eiΘf(𝐤,n)g(𝐪,𝐤,m−n)=Rg(𝐪,𝐤,m−n)eiΘg(𝐪,𝐤,m−n) \begin{aligned} f(\boldsymbol{q},m)&=R_f(\boldsymbol{q},m)e^{i\Theta_f(\boldsymbol{q},m)}\\ f(\boldsymbol{k},n)&=R_f(\boldsymbol{k},n)e^{i\Theta_f(\boldsymbol{k},n)}\\ g(\boldsymbol{q},\boldsymbol{k},m-n)&=R_g(\boldsymbol{q},\boldsymbol{k},m-n)e^{i\Theta_g(\boldsymbol{q},\boldsymbol{k},m-n)} \end{aligned} \tag{4}

那么代入方程后就得到方程组

{Rf(𝐪,m)Rf(𝐤,n)=Rg(𝐪,𝐤,m−n)Θf(𝐪,m)−Θf(𝐤,n)=Θg(𝐪,𝐤,m−n) \begin{cases} R_f(\boldsymbol{q},m)R_f(\boldsymbol{k},n)=R_g(\boldsymbol{q},\boldsymbol{k},m-n)\\[4pt] \Theta_f(\boldsymbol{q},m)-\Theta_f(\boldsymbol{k},n)=\Theta_g(\boldsymbol{q},\boldsymbol{k},m-n) \end{cases} \tag{5}

代入之后，等号两边自动分成两组：一组管模长（式 5 第一行），一组管角度（第二行）。因为复数的乘法规则就是「模长相乘、角度相加」。

对于第一个方程，代入 m=nm=n 得到

Rf(𝐪,m)Rf(𝐤,m)=Rg(𝐪,𝐤,0)=Rf(𝐪,0)Rf(𝐤,0)=∥𝐪∥∥𝐤∥ R_f(\boldsymbol{q},m)R_f(\boldsymbol{k},m)=R_g(\boldsymbol{q},\boldsymbol{k},0)=R_f(\boldsymbol{q},0)R_f(\boldsymbol{k},0)=\|\boldsymbol{q}\|\|\boldsymbol{k}\| \tag{6}

最后一个等号源于初始条件 f(𝐪,0)=𝐪f(\boldsymbol{q},0)=\boldsymbol{q} 和 f(𝐤,0)=𝐤f(\boldsymbol{k},0)=\boldsymbol{k}。

这里在说一件事：同一个位置和它自己比，长度不该变。所以 RfR_f 与位置 mm 无关，直接取 ∥𝐪∥\|\boldsymbol{q}\|。换成白话：旋转不改变长度。

至于第二个方程，同样代入 m=nm=n 得到

Θf(𝐪,m)−Θf(𝐤,m)=Θg(𝐪,𝐤,0)=Θf(𝐪,0)−Θf(𝐤,0)=Θ(𝐪)−Θ(𝐤) \Theta_f(\boldsymbol{q},m)-\Theta_f(\boldsymbol{k},m)=\Theta_g(\boldsymbol{q},\boldsymbol{k},0)=\Theta_f(\boldsymbol{q},0)-\Theta_f(\boldsymbol{k},0)=\Theta(\boldsymbol{q})-\Theta(\boldsymbol{k}) \tag{7}

这里的 Θ(𝐪),Θ(𝐤)\Theta(\boldsymbol{q}),\Theta(\boldsymbol{k}) 是 𝐪,𝐤\boldsymbol{q},\boldsymbol{k} 本身的幅角，最后一个等号同样源于初始条件。根据上式得到 Θf(𝐪,m)−Θ(𝐪)=Θf(𝐤,m)−Θ(𝐤)\Theta_f(\boldsymbol{q},m)-\Theta(\boldsymbol{q})=\Theta_f(\boldsymbol{k},m)-\Theta(\boldsymbol{k})，所以 Θf(𝐪,m)−Θ(𝐪)\Theta_f(\boldsymbol{q},m)-\Theta(\boldsymbol{q}) 应该是一个只与 mm 相关、跟 𝐪\boldsymbol{q} 无关的函数，记为 φ(m)\varphi(m)，即 Θf(𝐪,m)=Θ(𝐪)+φ(m)\Theta_f(\boldsymbol{q},m)=\Theta(\boldsymbol{q})+\varphi(m)。接着代入 n=m−1n=m-1，整理得到

φ(m)−φ(m−1)=Θg(𝐪,𝐤,1)+Θ(𝐤)−Θ(𝐪) \varphi(m)-\varphi(m-1)=\Theta_g(\boldsymbol{q},\boldsymbol{k},1)+\Theta(\boldsymbol{k})-\Theta(\boldsymbol{q}) \tag{8}

式 (8) 左边是相邻两个位置的角度差，右边是一个与 mm 无关的常数。每一步都加同一个常数，这个数列就是等差数列，设常数为 θ\theta，于是 φ(m)=mθ\varphi(m)=m\theta。

编码形式

综上，我们得到二维情况下用复数表示的 RoPE：

f(𝐪,m)=Rf(𝐪,m)eiΘf(𝐪,m)=∥𝐪∥ei(Θ(𝐪)+mθ)=𝐪eimθ f(\boldsymbol{q},m)=R_f(\boldsymbol{q},m)e^{i\Theta_f(\boldsymbol{q},m)}=\|\boldsymbol{q}\|e^{i(\Theta(\boldsymbol{q})+m\theta)}=\boldsymbol{q}e^{im\theta} \tag{9}

结论一句话：位置 mm 的作用，就是让向量逆时针转 mθm\theta 角，长度不变。这就是「旋转式位置编码」名字的由来。写成矩阵形式：

f(𝐪,m)=(cos⁡mθ−sin⁡mθsin⁡mθcos⁡mθ)(q0q1) f(\boldsymbol{q},m)=\begin{pmatrix}\cos m\theta & -\sin m\theta\\ \sin m\theta & \cos m\theta\end{pmatrix}\begin{pmatrix}q_0\\ q_1\end{pmatrix} \tag{10}

由于内积满足线性叠加性，因此任意偶数维的 RoPE，我们都可以表示为二维情形的拼接，即

𝐑m=(cos⁡mθ0−sin⁡mθ000⋯00sin⁡mθ0cos⁡mθ000⋯0000cos⁡mθ1−sin⁡mθ1⋯0000sin⁡mθ1cos⁡mθ1⋯00⋮⋮⋮⋮⋱⋮⋮0000⋯cos⁡mθd/2−1−sin⁡mθd/2−10000⋯sin⁡mθd/2−1cos⁡mθd/2−1),f(𝐪,m)=𝐑m𝐪 \boldsymbol{R}_m=\begin{pmatrix} \cos m\theta_0 & -\sin m\theta_0 & 0 & 0 & \cdots & 0 & 0\\ \sin m\theta_0 & \cos m\theta_0 & 0 & 0 & \cdots & 0 & 0\\ 0 & 0 & \cos m\theta_1 & -\sin m\theta_1 & \cdots & 0 & 0\\ 0 & 0 & \sin m\theta_1 & \cos m\theta_1 & \cdots & 0 & 0\\ \vdots & \vdots & \vdots & \vdots & \ddots & \vdots & \vdots\\ 0 & 0 & 0 & 0 & \cdots & \cos m\theta_{d/2-1} & -\sin m\theta_{d/2-1}\\ 0 & 0 & 0 & 0 & \cdots & \sin m\theta_{d/2-1} & \cos m\theta_{d/2-1} \end{pmatrix},\qquad f(\boldsymbol{q},m)=\boldsymbol{R}_m\boldsymbol{q} \tag{11}

高维怎么办？两两分组，每组当作一个二维平面各自旋转，每组用不同的角速度 θi\theta_i，所以 dd 维向量需要 d/2d/2 个角度。

也就是说，给位置为 mm 的向量 𝐪\boldsymbol{q} 乘上矩阵 𝐑m\boldsymbol{R}_m、位置为 nn 的向量 𝐤\boldsymbol{k} 乘上矩阵 𝐑n\boldsymbol{R}_n，用变换后的 Q,KQ,K 序列做 Attention，那么 Attention 就自动包含相对位置信息了，因为成立恒等式：

(𝐑m𝐪)⊤(𝐑n𝐤)=𝐪⊤𝐑m⊤𝐑n𝐤=𝐪⊤𝐑n−m𝐤 (\boldsymbol{R}_m\boldsymbol{q})^{\top}(\boldsymbol{R}_n\boldsymbol{k})=\boldsymbol{q}^{\top}\boldsymbol{R}_m^{\top}\boldsymbol{R}_n\boldsymbol{k}=\boldsymbol{q}^{\top}\boldsymbol{R}_{n-m}\boldsymbol{k} \tag{12}

这个式子说明：两个向量各自转完再做内积，结果只跟它们转过的角度差有关，也就是只跟 n−mn-m 有关。相对位置就这么自然出现了。

值得指出的是，𝐑m\boldsymbol{R}_m 是一个正交矩阵，它不会改变向量的模长，因此通常来说它不会改变原模型的稳定性。

由于 𝐑m\boldsymbol{R}_m 的稀疏性，所以直接用矩阵乘法来实现会很浪费算力，推荐通过下述方式来实现 RoPE：

(q0q1q2q3⋮qd−2qd−1)⊗(cos⁡mθ0cos⁡mθ0cos⁡mθ1cos⁡mθ1⋮cos⁡mθd/2−1cos⁡mθd/2−1)+(−q1q0−q3q2⋮−qd−1qd−2)⊗(sin⁡mθ0sin⁡mθ0sin⁡mθ1sin⁡mθ1⋮sin⁡mθd/2−1sin⁡mθd/2−1) \begin{pmatrix}q_0\\ q_1\\ q_2\\ q_3\\ \vdots\\ q_{d-2}\\ q_{d-1}\end{pmatrix}\otimes \begin{pmatrix}\cos m\theta_0\\ \cos m\theta_0\\ \cos m\theta_1\\ \cos m\theta_1\\ \vdots\\ \cos m\theta_{d/2-1}\\ \cos m\theta_{d/2-1}\end{pmatrix}+ \begin{pmatrix}-q_1\\ q_0\\ -q_3\\ q_2\\ \vdots\\ -q_{d-1}\\ q_{d-2}\end{pmatrix}\otimes \begin{pmatrix}\sin m\theta_0\\ \sin m\theta_0\\ \sin m\theta_1\\ \sin m\theta_1\\ \vdots\\ \sin m\theta_{d/2-1}\\ \sin m\theta_{d/2-1}\end{pmatrix} \tag{13}

实际写代码不用真的构造那个大矩阵，按这个公式逐位乘加就行，省算力。其中 ⊗\otimes 是逐位对应相乘，即 Numpy、Tensorflow 等计算框架中的 * 运算。从这个实现也可以看到，RoPE 可以视为是乘性位置编码的变体。

远程衰减

这一节回答一个问题：两个 token 隔得越远，注意力分数会不会自然变小一点？如果会，模型就更容易聚焦在邻近内容上。

做法是给每组一个不同的角速度，按 θi=10000−2i/d\theta_i=10000^{-2i/d} 递减。高频的那几组负责分近处，低频的那几组负责分远处。

可以看到，RoPE 形式上和 Sinusoidal 位置编码有点相似，只不过 Sinusoidal 位置编码是加性的，而 RoPE 可以视为乘性的。在 θi\theta_i 的选择上，我们同样沿用了 Sinusoidal 位置编码的方案，即 θi=10000−2i/d\theta_i=10000^{-2i/d}，它可以带来一定的远程衰减性。

具体证明如下：将 𝐪,𝐤\boldsymbol{q},\boldsymbol{k} 两两分组后，它们加上 RoPE 后的内积可以用复数乘法表示为

(𝐑m𝐪)⊤(𝐑n𝐤)=Re⁡[∑i=0d/2−1𝐪[2i:2i+1]𝐤[2i:2i+1]*ei(m−n)θi] (\boldsymbol{R}_m\boldsymbol{q})^{\top}(\boldsymbol{R}_n\boldsymbol{k})=\operatorname{Re}\left[\sum_{i=0}^{d/2-1}\boldsymbol{q}_{[2i:2i+1]}\boldsymbol{k}^{*}_{[2i:2i+1]}e^{i(m-n)\theta_i}\right] \tag{14}

记 hi=𝐪[2i:2i+1]𝐤[2i:2i+1]*h_i=\boldsymbol{q}_{[2i:2i+1]}\boldsymbol{k}^{*}_{[2i:2i+1]}，Sj=∑i=0j−1ei(m−n)θiS_j=\sum_{i=0}^{j-1}e^{i(m-n)\theta_i}，并约定 hd/2=0,S0=0h_{d/2}=0,S_0=0，那么由 Abel 变换（分部求和法）可以得到：

∑i=0d/2−1𝐪[2i:2i+1]𝐤[2i:2i+1]*ei(m−n)θi=∑i=0d/2−1hi(Si+1−Si)=−∑i=0d/2−1Si+1(hi+1−hi) \sum_{i=0}^{d/2-1}\boldsymbol{q}_{[2i:2i+1]}\boldsymbol{k}^{*}_{[2i:2i+1]}e^{i(m-n)\theta_i}=\sum_{i=0}^{d/2-1}h_i(S_{i+1}-S_i)=-\sum_{i=0}^{d/2-1}S_{i+1}(h_{i+1}-h_i) \tag{15}

所以

|∑i=0d/2−1𝐪[2i:2i+1]𝐤[2i:2i+1]*ei(m−n)θi|=|∑i=0d/2−1Si+1(hi+1−hi)|≤∑i=0d/2−1|Si+1||hi+1−hi|≤(maxi|hi+1−hi|)∑i=0d/2−1|Si+1| \begin{aligned} \left|\sum_{i=0}^{d/2-1}\boldsymbol{q}_{[2i:2i+1]}\boldsymbol{k}^{*}_{[2i:2i+1]}e^{i(m-n)\theta_i}\right| &=\left|\sum_{i=0}^{d/2-1}S_{i+1}(h_{i+1}-h_i)\right|\\ &\leq\sum_{i=0}^{d/2-1}|S_{i+1}||h_{i+1}-h_i|\\ &\leq\left(\max_i|h_{i+1}-h_i|\right)\sum_{i=0}^{d/2-1}|S_{i+1}| \end{aligned} \tag{16}

因此我们可以考察 1d/2∑i=1d/2|Si|\frac{1}{d/2}\sum_{i=1}^{d/2}|S_i| 随着相对距离的变化情况来作为衰减性的体现，Mathematica 代码如下：

d = 128;
\[Theta][t_] = 10000^(-2*t/d);
f[m_] = Sum[
    Norm[Sum[Exp[I*m*\[Theta][i]], {i, 0, j}]], {j, 0, d/2 - 1}]/(d/2);
Plot[f[m], {m, 0, 256}, AxesLabel -> {相对距离, 相对大小}]

结果如下图：

从图中我们可以看到随着相对距离的变大，内积结果有衰减趋势的出现。因此，选择 θi=10000−2i/d\theta_i=10000^{-2i/d}，确实能带来一定的远程衰减性。当然，同上一篇文章说的一样，能带来远程衰减性的不止这个选择，几乎任意的光滑单调函数都可以，这里只是沿用了已有的选择而已。笔者还试过以 θi=10000−2i/d\theta_i=10000^{-2i/d} 为初始化，将 θi\theta_i 视为可训练参数，然后训练一段时间后发现 θi\theta_i 并没有显著更新，因此干脆就直接固定 θi=10000−2i/d\theta_i=10000^{-2i/d} 了。

线性场景

这一节讲什么：常规 Attention 要先把所有 token 两两算一遍，序列越长越慢；线性 Attention 换了个算法，不显式算那张两两的矩阵，速度和长度成正比。

最后，我们指出，RoPE 是目前唯一一种可以用于线性 Attention 的相对位置编码。这是因为其他的相对位置编码，都是直接基于 Attention 矩阵进行操作的，但是线性 Attention 并没有事先算出 Attention 矩阵，因此也就不存在操作 Attention 矩阵的做法，所以其他的方案无法应用到线性 Attention 中。而对于 RoPE 来说，它是用绝对位置编码的方式来实现相对位置编码，不需要操作 Attention 矩阵，因此有了应用到线性 Attention 的可能性。

线性 Attention 的常见形式是：

Attention⁡(Q,K,V)i=∑j=1nsim⁡(𝐪i,𝐤j)𝐯j∑j=1nsim⁡(𝐪i,𝐤j)=∑j=1nϕ(𝐪i)⊤φ(𝐤j)𝐯j∑j=1nϕ(𝐪i)⊤φ(𝐤j) \operatorname{Attention}(Q,K,V)_i=\frac{\sum_{j=1}^{n}\operatorname{sim}(\boldsymbol{q}_i,\boldsymbol{k}_j)\boldsymbol{v}_j}{\sum_{j=1}^{n}\operatorname{sim}(\boldsymbol{q}_i,\boldsymbol{k}_j)}=\frac{\sum_{j=1}^{n}\phi(\boldsymbol{q}_i)^{\top}\varphi(\boldsymbol{k}_j)\boldsymbol{v}_j}{\sum_{j=1}^{n}\phi(\boldsymbol{q}_i)^{\top}\varphi(\boldsymbol{k}_j)} \tag{17}

其中 ϕ,φ\phi,\varphi 是值域非负的激活函数。可以看到，线性 Attention 也是基于内积的，所以很自然的想法是可以将 RoPE 插入到内积中：

∑j=1n[𝐑iϕ(𝐪i)]⊤[𝐑jφ(𝐤j)]𝐯j∑j=1n[𝐑iϕ(𝐪i)]⊤[𝐑jφ(𝐤j)] \frac{\sum_{j=1}^{n}\left[\boldsymbol{R}_i\phi(\boldsymbol{q}_i)\right]^{\top}\left[\boldsymbol{R}_j\varphi(\boldsymbol{k}_j)\right]\boldsymbol{v}_j}{\sum_{j=1}^{n}\left[\boldsymbol{R}_i\phi(\boldsymbol{q}_i)\right]^{\top}\left[\boldsymbol{R}_j\varphi(\boldsymbol{k}_j)\right]} \tag{18}

但这样存在的问题是，内积 [𝐑iϕ(𝐪i)]⊤[𝐑jφ(𝐤j)]\left[\boldsymbol{R}_i\phi(\boldsymbol{q}_i)\right]^{\top}\left[\boldsymbol{R}_j\varphi(\boldsymbol{k}_j)\right] 可能为负数，因此它不再是常规的概率注意力，而且分母有为 0 的风险，可能会带来优化上的不稳定。考虑到 𝐑i,𝐑j\boldsymbol{R}_i,\boldsymbol{R}_j 都是正交矩阵，它不改变向量的模长，因此我们可以抛弃常规的概率归一化要求，使用如下运算作为一种新的线性 Attention：

∑j=1n[𝐑iϕ(𝐪i)]⊤[𝐑jφ(𝐤j)]𝐯j∑j=1nϕ(𝐪i)⊤φ(𝐤j) \frac{\sum_{j=1}^{n}\left[\boldsymbol{R}_i\phi(\boldsymbol{q}_i)\right]^{\top}\left[\boldsymbol{R}_j\varphi(\boldsymbol{k}_j)\right]\boldsymbol{v}_j}{\sum_{j=1}^{n}\phi(\boldsymbol{q}_i)^{\top}\varphi(\boldsymbol{k}_j)} \tag{19}

也就是说，RoPE 只插入分子中，而分母则不改变。这样的注意力不再是基于概率的（注意力矩阵不再满足非负归一性），但它某种意义上来说也是一个归一化方案，而且也没有证据表明非概率式的注意力就不好（比如 Nyströmformer 也算是没有严格依据概率分布的方式构建注意力），所以我们将它作为候选方案之一进行实验，而我们初步的实验结果显示这样的线性 Attention 也是有效的。

此外，笔者在《线性 Attention 的探索：Attention 必须有个 Softmax 吗？》中还提出过另外一种线性 Attention 方案：sim⁡(𝐪i,𝐤j)=1+(𝐪i∥𝐪i∥)⊤(𝐤j∥𝐤j∥)\operatorname{sim}(\boldsymbol{q}_i,\boldsymbol{k}_j)=1+\left(\frac{\boldsymbol{q}_i}{\|\boldsymbol{q}_i\|}\right)^{\top}\left(\frac{\boldsymbol{k}_j}{\|\boldsymbol{k}_j\|}\right)，它不依赖于值域的非负性，而 RoPE 也不改变模长，因此 RoPE 可以直接应用于此类线性 Attention，并且不改变它的概率意义。

模型开源

RoFormer 的第一版模型，我们已经完成训练并开源到了 Github 中：

RoFormer：https://github.com/ZhuiyiTechnology/roformer

简单来说，RoFormer 是一个绝对位置编码替换为 RoPE 的 WoBERT 模型，它跟其他模型的结构对比如下：

  • BERT：字级 token，绝对位置编码
  • WoBERT：词级 token，绝对位置编码
  • NEZHA：字级 token，经典式相对位置编码
  • RoFormer：词级 token，RoPE

在预训练上，我们以 WoBERT Plus 为基础，采用了多个长度和 batch size 交替训练的方式，让模型能提前适应不同的训练场景：

  1. maxlen=512，batch size=256，训练 20 万步，最终 loss 1.73，最终 acc 65.0%
  2. maxlen=1536，batch size=256，训练 1.25 万步，最终 loss 1.61，最终 acc 66.8%
  3. maxlen=256，batch size=256，训练 12 万步，最终 loss 1.75，最终 acc 64.6%
  4. maxlen=128，batch size=512，训练 8 万步，最终 loss 1.83，最终 acc 63.4%
  5. maxlen=1536，batch size=256，训练 1 万步，最终 loss 1.58，最终 acc 67.4%
  6. maxlen=512，batch size=512，训练 3 万步，最终 loss 1.66，最终 acc 66.2%

从表格还可以看到，增大序列长度，预训练的准确率反而有所提升，这侧面体现了 RoFormer 长文本语义的处理效果，也体现了 RoPE 具有良好的外推能力。在短文本任务上，RoFormer 与 WoBERT 的表现类似，RoFormer 的主要特点是可以直接处理任意长的文本。下面是我们在 CAIL2019-SCM 任务上的实验结果（后面的参数是微调时截断的 maxlen）：

  • BERT-512：验证集 64.13%，测试集 67.77%
  • WoBERT-512：验证集 64.07%，测试集 68.10%
  • RoFormer-512：验证集 64.13%，测试集 68.29%
  • RoFormer-1024：验证集 66.07%，测试集 69.79%

可以看到 RoFormer 确实能较好地处理长文本语义，至于设备要求，在 24G 显存的卡上跑 maxlen=1024，batch size 可以跑到 8 以上。目前中文任务中笔者也就找到这个任务比较适合作为长文本能力的测试，所以长文本方面只测了这个任务，欢迎读者进行测试或推荐其他评测任务。

当然，尽管理论上 RoFormer 能处理任意长度的序列，但目前 RoFormer 还是具有平方复杂度的，我们也正在训练基于线性 Attention 的 RoFormer 模型，实验完成后也会开源放出。

文章小结

RoPE 的思路可以用三句话概括：

  1. 位置不直接加到向量上，改成让向量转一个角度，转多少与位置编号成正比。
  2. 两个向量各自转完再算内积，结果只依赖它们转过的角度差，也就是只依赖相对距离。
  3. 旋转不改变长度，所以不会破坏原有表示，还顺带能用在更省显存的线性 Attention 上。

RoFormer 的预训练结果显示，它在长文本上表现更稳，这也侧面印证了 RoPE 的外推能力。

疑问

位置编码为什么都往相对位置方向走

你问的是：既然绝对位置编码实现简单、计算也快，为什么主流方案仍然朝着相对位置编码的方向走。

核心原因在于语言本身依赖相对关系。决定语义的是两个 token 相隔多远，它们在句中的绝对编号并不起决定作用。

graph LR
    A["猫 追 狗<br/>猫在第 1 位"] -->|前面插一句| B["昨天 猫 追 狗<br/>猫在第 2 位"]
    A -.->|"猫到狗仍是 2 步"| B

同一个「猫追狗」，前面加两字，所有 token 的绝对位置都变了，而词与词的距离没变。绝对位置编码会把整句的表示都改一遍，相对位置编码的表示不变，这就是平移不变性。文中式 (2) 的恒等式 ⟨f(q,m),f(k,n)⟩=g(q,k,m−n)\langle f(q,m),f(k,n)\rangle=g(q,k,m-n) 正是把这一点写成要求：内积只依赖 m−nm-n。

其中 f(q,m)f(q,m) 表示给查询 qq 施加位置 mm，f(k,n)f(k,n) 表示给键 kk 施加位置 nn，左边是注意力的打分。换句话说，两个 token 谁在第几位并不重要，重要的是它们相隔多远。

graph TB
    ABS["绝对位置：为每个位置学一个向量"] --> P1["位置表随最大长度增长"]
    ABS --> P2["超出训练长度 = 没见过的位置"]
    REL["相对位置：只依赖距离"] --> Q1["参数量与长度无关"]
    REL --> Q2["训练 512、推理 2048 仍落在见过的距离范围"]

四个直接好处

  • 长度外推：训练时最长 512，推理时遇到第 1000 个位置，绝对编码给出的是训练中从未出现的向量，性能骤降；相对编码只需要「距离」落在见过的区间，这也是 RoPE 能外推的原因。
  • 数据效率：相对编码共享同一套「距离→偏置」的规律，不必为每个位置单独积累数据。
  • 参数与显存：可学习的绝对位置表随上下文长度线性增长，相对偏置表只与距离桶数有关。
  • 贴合 Attention 的形式：相对信息可以直接加到注意力分数上（ALiBi 的线性偏置、T5 的距离分桶），不需要改动 Q、K 本身。

绝对位置编码仍然没有退场：它实现简单，能表达「句首」「结尾」这类与绝对次序有关的信号，某些任务确实需要它。当前主流的做法是把绝对位置编码做成在效果上等价于相对位置的形式；RoPE 就是在这一点上满足这个要求的：==形式上是绝对位置编码，内积里却只剩相对距离==。
