**正则表达式就是用来描述“文字长什么样”的模板**，你写好模板，程序就会帮你在长文本里找出符合它的片段。它由 6 类零件组成：

| 零件  | 写法                        | 含义                                |
| --- | ------------------------- | --------------------------------- |
| 字符类 | `\d` `\w` `\s` `.`        | 数字、字**母数字下划线**、空白、任意字符（不含换行）      |
| 集合  | `[abc]` `[^abc]`          | 其中任一字符；排除这些字符                     |
| 量词  | `*` `+` `?` `{3}` `{2,5}` | 0 次、1 次或多次、0 或 1 次、恰好 3 次、2 到 5 次 |
| 位置  | `^` `$` `\b`              | 行首、行尾、单词边界（只表示位置，不占字符）            |
| 分组  | `(...)` `(?:...)` `a\|b`  | 捕获、不捕获、或                          |
| 转义  | `\.` `\\`                 | 让特殊符号变回普通字符                       |

量词默认是**贪婪**的：能多吃就多吃；在它后面加 `?` 会变成懒惰，比如 `.*?`。

`re.match`（从开头比较）、`re.search`（全文找第一个）、`re.findall`（找全部）、`re.sub`（替换）。

```python
import re
log = "2026-11-10 19:39:12 ERROR 10.0.0.5 timeout"

m = re.search(r"(\d{4}-\d{2}-\d{2}) (\d{2}:\d{2}:\d{2}).*?(\d+\.\d+\.\d+\.\d+)", log)

print(m.group(1), m.group(2), m.group(3))   
# 2026-11-10 19:39:12 10.0.0.5
```

要点是先看 `group(1)` 这些括号，它们就是被提取出的那几部分；`.*?` 用来跳过中间的 "ERROR"。
