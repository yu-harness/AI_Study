## 鸭子类型案例（无基类，照样统一调用）

**python**

复制

```python
# 两个完全无关的类，没有任何共同父类
class Dog:
    def speak(self):
        return "汪汪"

class Robot:
    def speak(self):
        return "哔哔"

# 统一的函数：它不关心传进来的是 Dog 还是 Robot
# 只关心"你这个对象有没有 speak 这个方法"
def make_speak(thing):
    return thing.speak()      # ← 运行时才去找 thing 有没有 speak

print(make_speak(Dog()))     # 汪汪
print(make_speak(Robot()))    # 哔哔
```

**关键观察**：
- `make_speak` 没有类型声明、没有 `isinstance` 检查、没有要求继承谁；
- Python 跑到 `thing.speak()` 这一行时，才去 `thing` 里找 `speak` 方法：找到了就调，找不到才报 `AttributeError`；
- `Dog` 和 `Robot` 都没声明"我是 Speaker"，但它们**都会 `speak`**，所以都能被 `make_speak` 当 Speaker 用。

这就是"走起来像鸭子、叫起来像鸭子，就是鸭子"——**不看血统（父类），看行为（有没有这个方法）**。
