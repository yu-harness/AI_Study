# PyTorch 够用版：只为看懂大模型代码

不用系统学 PyTorch。看懂 KV Cache、RoPE、Loss 这些代码，只需要下面五件事。

## 一、张量就是「带形状的多维数组」

```python
x = torch.randn(2, 3)      # 形状 (2, 3)：2 行 3 列
x.shape                    # torch.Size([2, 3])
```

大模型里所有形状你只需认三个字母：

| 符号 | 意思 | 例子 |
| --- | --- | --- |
| `B` | batch，一次送几条 | 4 |
| `S` | sequence，每条几个 token | 512 |
| `V` / `d` | 词表大小 / 隐藏维度 | 151936 / 3584 |

看到 `(B, S, V)` 就读成「4 条、每条 512 个位置、每个位置 15 万个词的分数」。**读代码时先看形状，再看逻辑**，一半的困惑会消失。

## 二、`.view()` 和 `.reshape()`：只改形状，不改数据

```python
x = torch.randn(2, 3, 4)
x.view(6, 4)        # (2*3, 4)，元素总数不变
x.view(-1, 4)       # -1 表示「这一维你自己算」，结果同上
```

`-1` 是偷懒写法：总数 24，另一维给了 4，那这维必然是 6。

所以 `logits.view(-1, logits.size(-1))` 的含义就是：**把前面所有维压成一维，最后一维（词表 V）不动**，得到 `(B*S, V)`。

`.reshape()` 与 `.view()` 几乎等价，区别是 `view` 要求内存连续，不连续时用 `reshape` 或先 `.contiguous()`。

## 三、`transpose` 与广播：换轴、自动对齐

```python
x.transpose(1, 2)              # 交换第 1、2 维： (B,S,h,d) → (B,h,S,d)
q @ k.transpose(-2, -1)        # 矩阵乘：(B,h,S,d) @ (B,h,d,S) → (B,h,S,S)
```

### 这一行为什么要 transpose

先去掉 batch 和 head，只看最小情况：3 个 token、每个 token 的向量是 2 维。

```text
q: (3, 2)        k: (3, 2)
```

目标：**每个 q 和每个 k 算一次点积**，结果应该是 3×3 的表格，第 i 行第 j 列就是 $q_i\cdot k_j$。

矩阵乘法的规则是「左边每一行 · 右边每一列」，所以右边必须变成 2 行 3 列（行数 = 左边列数 2）：

```text
k.transpose(-2, -1) → (2, 3)

q(3,2) @ kᵀ(2,3) → (3,3)

         k1  k2  k3
     ┌─────────────┐
q1   │ ●   ●   ●  │   ● = q_i · k_j
q2   │ ●   ●   ●  │
q3   │ ●   ●   ●  │
     └─────────────┘
```

`.transpose(-2, -1)` 的意思是「把倒数第二维和最后一维换位置」。在 `(B, h, S, d)` 里换掉 `S` 和 `d`，得到 `(B, h, d, S)`，然后 `(B,h,S,d) @ (B,h,d,S)` 就得到 `(B,h,S,S)` 的分数矩阵。

**为什么不做除法、不做 softmax**：这一句只负责「算相似度」，缩放和归一化是后面两句的事。

广播（broadcasting）：**当两个形状某一维长度不同、其中一个是 1 时，那个 1 会被"拉长"成对方的长度。**

举个能心算的例子：

```python
a = torch.tensor([[1], [2]])        # 形状 (2, 1)
b = torch.tensor([10, 20, 30])      # 形状 (3,)
a + b
# tensor([[11, 21, 31],
#         [12, 22, 32]])            # 形状 (2, 3)
```

发生了什么：

```text
a:  [1]  →  [[1, 1, 1],
     [2]      [2, 2, 2]]      横向复制 3 次
b:  [10, 20, 30] → [[10, 20, 30],
                    [10, 20, 30]]   纵向复制 2 次
```

所以结果是 `(2,3)`：**长度 1 的那一维无条件复制成对方的长度**，不是"选大的"，也不是"随机对齐"。

MQA 就靠这个：`k` 的形状是 `(B, 1, S, d)`，头维是 1，和 `q` 的 `(B, h, S, d)` 相乘时，那 1 个头被自动复制成 h 份——**省下的是显存，不是计算正确性**。

```python
a = torch.randn(4, 1, 8)       # 第 2 维是 1
b = torch.randn(4, 6, 8)
(a + b).shape                  # (4, 6, 8)，那个 1 被自动铺开
```

MQA 就是靠这个：`k` 的头维是 1，被 $h$ 个 Q 头共用，不用真的复制。

## 四、函数调用：位置参数 vs 关键字参数

```python
F.cross_entropy(logits, labels, ignore_index=-100)
```

先把三个词认清楚，它们是一条链上的三样东西：

| 名字 | 是什么 | 形状 | 一句话 |
| --- | --- | --- | --- |
| `logits` | 模型**打的原始分**，还没变成概率 | `(B, S, V)` | 对词表里每个词各打一个分，可正可负 |
| `labels` | **正确答案**，也就是每个位置应该是哪个词 | `(B, S)` | 存的是词 id，如 9906 |
| `loss` | 打分和答案**差多远**，压成一个数 | 标量 | 越小越好，训练就是把它压下去 |

举个例子：某位置模型给四个词打分 `[2.0, 0.1, -1.0, 0.3]`，正确答案是第 1 个（id=1）。

- 先 softmax 把分数变成概率：约 `[0.66, 0.10, 0.03, 0.12]`，第 1 个词的概率是 0.66；
- 再算 $-\log(0.66)\approx 0.42$，这就是这个位置的 loss；
- 如果模型给正确答案 0.99 的概率，loss 只有 0.01——**越自信答对，loss 越小**。

> 为什么 softmax 之后要取 $-\log$、为什么 loss 这样设计：见 [[深度学习#为什么用 log：三条理由与一张数值表]]。

拆开看这三个参数：

| 参数                  | 类型    | 说明                         |
| ------------------- | ----- | -------------------------- |
| `logits`            | 位置参数  | 第 1 个，模型打的分                |
| `labels`            | 位置参数  | 第 2 个，正确答案                 |
| `ignore_index=-100` | 关键字参数 | 带名字的开关，标签为 -100 的位置不算 loss |

- 逗号按顺序传的，叫**位置参数**，顺序不能错。
- 写成 `名字=值` 的，叫**关键字参数**，顺序随意，通常有默认值。

`ignore_index=-100` 就是「遇到标签是 -100 的位置，别算进 loss」。它是个**开关**，不写就默认 `-100` 之外全算。

代码里的 `...` 不是语法，是作者示意「此处省略若干参数」：

```python
cross_entropy(..., ignore_index=-100)   # 意思是：前面已经传了 logits 和 labels
```

## 五、三个最常用的操作

```python
x.unsqueeze(0)          # 在第 0 维插一个 1： (S,d) → (1,S,d)，造 batch 维
x.mean(dim=-1)          # 沿最后一维求平均
x.softmax(dim=-1)       # 沿最后一维归一化成概率
```

`dim=-1` 是「最后一维」的写法，`dim=0` 是第一维。softmax 一定要指定 dim，指定错就是全错。

## 拿这段代码练手

```python
import torch
import torch.nn.functional as F

B, S, V = 1, 3, 4
logits = torch.randn(B, S, V)                 # (1,3,4)
labels = torch.tensor([[1, 2, -100]])         # (1,3)

flat_logits = logits.view(-1, V)              # (3,4)：3 行，每行 4 个分数
flat_labels = labels.view(-1)                 # (3,)：3 个答案，最后一个是 -100
loss = F.cross_entropy(flat_logits, flat_labels, ignore_index=-100)

print(flat_logits.shape, flat_labels.shape, loss)
```

你自己改一下 `S`、`V`，看看形状怎么变；再把 `-100` 换成 `0`，观察 loss 是否变化——变了就说明最后那个位置确实参与了计算。

## 学习顺序建议

1. 张量形状 + `view` / `transpose`（今天就能会）；
2. 矩阵乘与广播（理解 attention 必备）；
3. `softmax` / `mean` / 索引切片；
4. 反向传播与 `optimizer.step()`（写训练循环时才需要）。

前三条大约两小时能过完，足够看懂大模型推理代码；第四条要动手训一次才记得住。
