**ReLU**（Rectified Linear Unit，修正线性单元）是深度学习中最基础且应用最广泛的**非线性激活函数**。

它的逻辑极其简单粗暴：**“保留正数，负数归零”**。
### 1. 数学定义与导数
**函数公式：**

  

$$f(x) = \max(0, x) = \begin{cases} x, & x > 0 \\ 0, & x \le 0 \end{cases}$$
**导数（梯度）：**

$$f'(x) = \begin{cases} 1, & x > 0 \\ 0, & x < 0 \end{cases}$$
_(在 $x = 0$ 处数学上不可导，工程实现中通常默认设为 0 或 1)_
### 2. 为什么深度学习偏爱 ReLU？

在 ReLU 普及之前，神经网络普遍使用 **Sigmoid** 或 **Tanh**。ReLU 的出现解决了当时深度网络训练的核心痛点：

- **彻底克服正向梯度消失**：
    Sigmoid/Tanh 在输入绝对值较大时会进入“饱和区”，导数趋近于 0，导致深层网络**无法反向传播梯度**。而 ReLU 在 $x > 0$ 时导数恒为 1，梯度能无衰减地向后传递，使得训练几十甚至上百层的深层网络成为可能。
- **计算速度极快**：
    Sigmoid/Tanh 包含复杂的指数和除法运算（$e^x$），而 ReLU 只需要一个简单的比较指令（判断是否大于 0），在 GPU 上计算效率极高。
- **带来稀疏激活性（Sparsity）**：
    当输入小于 0 时神经元输出为 0，相当于让一部分神经元处于“关闭”状态。这模拟了**生物神经元**的稀疏激活特性，能降低参数间的冗余依赖，提升模型泛化能力。

### 3. 主要缺点与改进版本
- **Dying ReLU（神经元死亡现象）**：
    如果学习率过大，导致某些神经元的输入始终处于负数区间，其输出为 0 且梯度也为 0。该神经元的权重将永远无法再被更新，彻底“死掉”。
- **改进演进**：
    - **Leaky ReLU / PReLU**：给**负半轴一个微小的斜率**（如 $f(x) = \max(0.01x, x)$），让负区间也能传递微弱梯度。
    - **GeLU / SwiGLU**：现代大语言模型（如 GPT、BERT、LLaMA）更倾向使用的**平滑非线性函数**，结合了**随机正则化**的思想，在零点附近平滑可导，表现优于硬截断的 ReLU。
