   - **亮点设计**：每次运行结束都落存档；**中途碰到三种情况也立刻存档** —— 上下文被裁剪（`budget_reductions`）/ 存档部分过期（`freshness_mismatch`）/ 运行环境不一致（`workspace_mismatch`）；这就是存档字段里有"触发原因"的原因

**当前进度**：12。核心主线：主循环 → 工具边界 → 上下文 → 记忆 → 全链路串讲。
