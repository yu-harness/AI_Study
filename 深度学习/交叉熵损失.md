# 交叉熵损失

## 定义

衡量**两个概率分布的差异**：模型预测的分布 vs 真实标签的分布。

$$H(\mathbf{p},\mathbf{q})=\sum_i-p_i\log q_i$$

$\mathbf{p}$ 是真实标签（one-hot），$\mathbf{q}$ 是模型输出的概率。因为 one-hot 只有正确那一项为 1，求和后只剩一格：

$$l=-\log q_c$$

## 数值感受：给正确答案多少概率，扣多少分

| 模型给正确答案的概率 | 损失 | 直白理解 |
| --- | --- | --- |
| 1.00 | 0 | 完全押对，一分不扣 |
| 0.90 | 0.11 | 很确定，扣一点点 |
| 0.70 | 0.36 | — |
| 0.50 | 0.69 | 相当于猜硬币 |
| 0.40 | 0.92 | — |
| 0.10 | 2.30 | 基本押错 |
| 0.01 | 4.61 | 几乎完全押反 |

**判断标准**：这个数叫「损失」，越小越好，0 是满分（相当于考试扣分）。

## 算一遍

三分类，真值第 0 类（$\mathbf{p}=[1,0,0]$），模型给 $\mathbf{q}=[0.7,0.2,0.1]$：

$$H=-\big(1\times\log0.7+0\times\log0.2+0\times\log0.1\big)=-\log0.7\approx0.357$$

换一组更差的预测 $\mathbf{q}=[0.4,0.3,0.3]$，同一公式得 $-\log0.4\approx0.916$。

对比两者：$0.357<0.916$，说明第一组更好——**给正确答案的概率越低，损失越大**；若 $\mathbf{q}=[1,0,0]$，损失正好为 0。

整条序列的 loss 就是把每个位置这么算一遍再平均。

## 为什么「罚」不是线性的

同样是掉 0.1 的概率，位置不同，代价差很多：

| 从多少掉到多少 | 损失涨了多少 |
| --- | --- |
| 1.00 → 0.90 | 0 → 0.11（涨 0.11） |
| 0.10 → 0.01 | 2.30 → 4.61（涨 2.31） |

越接近「完全押错」，损失涨得越快——这正是 $-\log$ 曲线在 0 附近迅速上扬的形状，目的是逼模型不敢把正确答案判成 0 概率。

## 梯度：预测概率减真实标签

对 softmax + 交叉熵求导，结果异常干净：

$$\frac{\partial l}{\partial o_i}=q_i-y_i$$

三分类、真值第 0 类、预测 $[0.7,0.2,0.1]$ 时，梯度为 $[-0.3,0.2,0.1]$：答对的那类往下压，错的两类往上抬。

两点意义：

- 没有 exp、没有除法，**数值稳定**
- 形式极简，所以框架把 softmax 与交叉熵合成一个 kernel（PyTorch 的 `F.cross_entropy`），不需要先手动 softmax

## 与 MSE 的分工

| | MSE / L1 | 交叉熵 |
| --- | --- | --- |
| 任务 | 回归：房价、温度、股价 | 分类：猫/狗/鸟 |
| 输出 | 实数 | 概率分布（softmax 后） |
| 量什么 | 数值**差多远** | 分布**差多少** |
| 错得自信时 | 不加罚 | **罚得极重**：$-\log0.01\approx4.6$ |

$$l_{\text{MSE}}=\tfrac12(y-y')^2\qquad l_{\text{CE}}=-\log q_c$$

分类网络最后一层先 softmax 再算 $-\log q_c$；回归输出没有概率，只能用 MSE / L1。细节见 [[深度学习#06 均方误差与 L1-L2 损失]]。

## 为什么用 log

| 问题 | 为什么是 log |
| --- | --- |
| 概率连乘会下溢 | 序列概率是 $T$ 个词连乘，取 log 变成连加，数值稳定 |
| 要惩罚「错得离谱」 | $p\to0$ 时 $-\log p\to\infty$ |
| 完全答对应无损失 | $p=1$ 时 $-\log1=0$ |

所以 **loss 衡量的不是「错了几个」，而是「对正确答案有多不自信」**。

## KL 散度与交叉熵

KL 回答「用分布 $q$ 近似分布 $p$，会多吃多少亏」，等于交叉熵减掉 $p$ 的熵：

$$D_{\text{KL}}(p\,\|\,q)=\sum_i p_i\log\frac{p_i}{q_i}=\underbrace{-\sum_i p_i\log q_i}_{\text{交叉熵}}-\underbrace{\left(-\sum_i p_i\log p_i\right)}_{\text{p 的熵}}$$

| 性质 | 说明 |
| --- | --- |
| 非负 | $D_{\text{KL}}\ge0$，当且仅当 $p=q$ 时为 0 |
| 不对称 | $D_{\text{KL}}(p\|q)\ne D_{\text{KL}}(q\|p)$，不是距离 |
| 与交叉熵同向 | $p$ 固定时熵为常数，**最小化交叉熵 = 最小化 KL** |

数值例子：$p=[1,0]$、$q=[0.9,0.1]$ 时 $D_{\text{KL}}=-\log0.9\approx0.105$；若 $q=[0.5,0.5]$，则 $D_{\text{KL}}=\log2\approx0.693$。

LLM 里两个用途：RLHF/PPO 约束新策略不偏离参考模型（见 [[2.2.9 PPO]]）；蒸馏时让学生分布逼近老师分布。
