## 为什么仅叠加多个线性层不能提升模型的表达能力？激活函数在多层感知机中起什么作用？

两层线性层可以合并成一层：
$$W_2(W_1 x + b_1) + b_2 = (W_2 W_1)\,x + (W_2 b_1 + b_2) = W' x + b'$$

无论叠多少层，整体仍是一个**线性变换**，表达能力等同于单层。

激活函数给网络引入**非线性**，让每层不再能被合并，网络才能逐层组合出复杂的特征和曲面形状的决策边界
## ReLU、Sigmoid 和 Tanh 的函数形式与梯度特点分别是什么？它们各自容易出现什么训练问题？

**ReLU：**
$$f(x) = \max(0, x), \qquad f'(x) = \begin{cases} 1, & x > 0 \\ 0, & x < 0 \end{cases}$$
- 计算简单，正区间不饱和。
- 问题：**Dead ReLU**，神经元输出长期为**负**时梯度恒为 0，参数不再更新；输出非零中心。

**Sigmoid：**

$$f(x) = \frac{1}{1 + e^{-x}}, \qquad f'(x) = f(x)\,\bigl(1 - f(x)\bigr) \le 0.25$$

- 问题：两端饱和导致**梯度消失**；输出恒正（非零中心），使梯度更新呈 zig-zag；含指数运算，较慢。

**Tanh：**

$$f(x) = \frac{e^{x} - e^{-x}}{e^{x} + e^{-x}}, \qquad f'(x) = 1 - f(x)^2 \le 1$$

- 零中心，比 Sigmoid 好，但两端仍会饱和，深层网络仍然**梯度消失**。

## 请写出 Softmax 函数和交叉熵损失函数。计算 Softmax 时为什么通常要先减去输入向量中的最大值？

**Softmax：**
$$\hat{y}_i = \frac{\exp(z_i)}{\sum_j \exp(z_j)}$$

**交叉熵：**
$$L = -\sum_i y_i \log(\hat{y}_i)$$

one-hot 标签时，只有真实类别 $c$ 对应的 $y_c = 1$，上式化简为：
$$L = -\log(\hat{y}_c)$$

**为什么减去最大值：** 防止**数值溢出**。当 $z_i$ 很大（如 1000）时，$\exp(z_i)$ 会上溢成 inf，得到 NaN。令 $m = \max_j z_j$，分子分母同乘 $\exp(-m)$ 后结果不变：

$$\frac{\exp(z_i - m)}{\sum_j \exp(z_j - m)} = \frac{\exp(z_i)}{\sum_j \exp(z_j)}$$

此时最大项为 $\exp(0) = 1$，不会上溢，分母至少为 1，也避免了除以 0。实践中通常直接用 `log_softmax` / log-sum-exp 技巧，同样保证数值稳定。



## 请结合计算图说明一次前向传播和反向传播的完整过程。链式法则在参数梯度计算中如何使用？

以"输入 → 隐藏层 → 输出层 → 损失"的两层 MLP 为例，计算图如下：

```
x ──► z1 ──► a1 ──► z2 ──► ŷ ──► L
```

**前向传播：**

$$  
\begin{aligned}  
z_1 &= W_1 x + b_1 \\  
a_1 &= \sigma(z_1) \\  
z_2 &= W_2 a_1 + b_2 \\  
\hat{y} &= \mathrm{softmax}(z_2) \\  
L &= \mathrm{CE}(\hat{y}, y)  
\end{aligned}  
$$

**反向传播**（沿**箭头反**方向，逐节点乘以局部导数）：
$$  
\begin{aligned}  
\frac{\partial L}{\partial z_2} &= \hat{y} - y \quad \text{（Softmax + 交叉熵合并后的简洁形式）} \\[4pt]  
\frac{\partial L}{\partial W_2} &= \frac{\partial L}{\partial z_2}\, a_1^{\top}, \qquad \frac{\partial L}{\partial b_2} = \frac{\partial L}{\partial z_2} \\[4pt]  
\frac{\partial L}{\partial a_1} &= W_2^{\top}\, \frac{\partial L}{\partial z_2} \\[4pt]  
\frac{\partial L}{\partial z_1} &= \frac{\partial L}{\partial a_1} \odot \sigma'(z_1) \\[4pt]  
\frac{\partial L}{\partial W_1} &= \frac{\partial L}{\partial z_1}\, x^{\top}, \qquad \frac{\partial L}{\partial b_1} = \frac{\partial L}{\partial z_1}  
\end{aligned}  
$$

**链式法则的使用：** 任意参数的梯度，等于从损失到该参数路径上所有局部导数的乘积，例如：

$$  
\frac{\partial L}{\partial W_1}  
= \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial z_2} \cdot \frac{\partial z_2}{\partial a_1} \cdot \frac{\partial a_1}{\partial z_1} \cdot \frac{\partial z_1}{\partial W_1}  
$$

反向传播的本质是**复用中间结果**：每层只需把上游传来的梯度 $\partial L / \partial(\text{本层输出})$ 乘以本层局部导数，再传给下一层，避免重复计算。前向传播时需缓存各层的 $x, z, a$，反向时要用到。

## 为什么深层网络容易出现梯度消失和梯度爆炸？Xavier 初始化与 He 初始化分别适用于什么激活函数？


**原因：** 反向传播中，浅层的梯度是**多层雅可比矩阵**（权重 × 激活函数导数）的连乘。若每层的因子平均小于 1，梯度随深度指数**衰减**（消失）；大于 1 则指数增长（爆炸）。常见**诱因**有：Sigmoid / Tanh 饱和（导数很小）、权重初始化过小或过大、网络过深。

**初始化：** 目标是让各层前向激活和反向梯度的**方差大致保持不变**。

**Xavier 初始化**，适用于 **Sigmoid / Tanh**（近似线性、零中心对称的激活）：

$$\mathrm{Var}(w) = \frac{2}{n_{\text{in}} + n_{\text{out}}}$$

**He 初始化**，适用于 **ReLU 及其变体**（ReLU 会把约一半的输出置零，需要更大的方差来补偿）：

$$\mathrm{Var}(w) = \frac{2}{n_{\text{in}}}$$

其他缓解手段：**批量规范化**、**残差连接**、**梯度裁剪**（针对爆炸）、换用 ReLU 系激活。

## 训练误差和验证误差分别出现什么特征时，可以判断模型发生了欠拟合或过拟合？应该如何针对性处理？

| 训练误差 | 验证误差 | 特征         |                   |
| ---- | ---- | ---------- | ----------------- |
| 欠拟合  | 高    | 高，且与训练误差接近 | 模型没学会             |
| 过拟合  | 很低   | 明显更高       | 训练-验证差距大，验证误差先降后升 |

**欠拟合的处理：**

- 增加**模型容量**（更多层 / 更多神经元）
- 训练更久，调整学习率或优化器
- 减弱正则化
- 改进特征 / 输入表示

**过拟合的处理：**

- 增加数据或做数据增强
- 权重衰减、Dropout 等正则化
- 早停（Early Stopping）
- 减小模型规模
- 使用批量规范化、集成方法


## 权重衰减、Dropout 和批量规范化分别如何影响模型训练？Dropout 和批量规范化在训练模式与预测模式下有什么差异？

**权重衰减（L2 正则）：** 损失加上正则项，更新时每步都让权重向 0 收缩。它限制权重大小，使函数更平滑，降低过拟合。
$$L' = L + \frac{\lambda}{2}\,\lVert w \rVert^2$$ $$w \leftarrow (1 - \eta\lambda)\,w - \eta \nabla L$$

**Dropout：** 训练时以概率 $p$ 随机将神经元输出置 0，并把保留的输出除以 $1 - p$（inverted dropout）。它阻止神经元之间的"共适应"，相当于训练许多子网络的集成。

**批量规范化（BN）：** 对每个 mini-batch，按特征维度做标准化，再用可学习的 $\gamma, \beta$ 缩放平移。它稳定各层输入分布，缓解梯度问题，允许更大的学习率，加快收敛，并带来轻微的正则效果。

$$\hat{x} = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}}, \qquad y = \gamma \hat{x} + \beta$$

**训练与预测模式的差异：**

- **Dropout：** 训练时随机丢弃；预测时**不丢弃**，使用全部神经元，输出确定。因为训练时已除以 $1 - p$，预测时无需再缩放。
- **BN：** 训练时用**当前 batch 的均值和方差**归一化，并用滑动平均更新全局统计量；预测时用训练期间累积的**全局滑动均值 / 方差**，使输出不依赖 batch，结果确定。

这就是 PyTorch 中必须正确切换 `model.train()` 和 `model.eval()` 的原因。

## 一个 MLP 的训练损失始终不下降，请给出完整的排查顺序，至少包括数据、标签、网络输出、损失函数、梯度、学习率和参数更新

建议**由简到繁、由前到后**逐步排查：
1. **先做小样本过拟合测试**：取一个很小的 batch（如 10~50 个样本）反复训练，损失应能降到接近 0。做不到，说明代码或模型有 bug，而不是调参问题。
2. **数据**：可视化样本，检查预处理是否正确（归一化、尺寸、通道）、是否有 NaN / 异常值、是否打乱、训练与测试预处理是否一致，DataLoader 是否正常取数。
3. **标签**：标签与输入是否对齐，标签范围是否在 $[0, C-1]$、类型是否正确（如 CrossEntropyLoss 要求 long 类型的类别索引），类别是否严重不平衡，是否有大量噪声标签。
4. **网络输出**：检查输出 shape；PyTorch 的 `CrossEntropyLoss` 内部已含 softmax，**不要在网络最后再加 softmax**；最后一层不加激活；初始损失应接近 $\ln C$（10 分类时 $\ln 10 \approx 2.30$），明显偏离说明有问题；检查输出是否全相同、含 NaN，是否出现 Dead ReLU，初始化是否合适。
5. **损失函数**：是否与任务匹配（分类用交叉熵，回归用 MSE），`reduction` 设置是否正确，计算过程是否误用了 `detach()` 或 `.item()` 切断了计算图。
6. **梯度**：每次迭代前是否 `zero_grad()`，`backward()` 是否被调用，各层参数的 `grad` 是否为 None / 全 0 / NaN / 过大，`requires_grad` 是否为 True，观察各层梯度范数的分布，判断是否梯度消失或爆炸。
7. **学习率**：过大则震荡或发散，过小则几乎不降。可尝试用 Adam（学习率 $10^{-3}$）作为基线，或做学习率扫描；检查学习率调度器是否把学习率衰减得过早、过快。
8. **参数更新**：参数是否都已传给优化器，`optimizer.step()` 是否被调用，更新前后参数值是否真的发生变化，权重衰减是否过大把权重压成 0。
9. **其他**：batch size、正则强度（Dropout / 权重衰减是否过强）、模型容量是否太小、`train()` / `eval()` 模式是否误用；最后用一个简单基线（如 Softmax 回归）对比，确认问题出在 MLP 本身还是整个流程

# CNN

## 1. 为什么全连接不适合高分辨率图像？局部连接和平移等变性各解决什么？

全连接的问题有两个：

- **参数爆炸**：224×224×3 的图展平后是 150,528 维，接 1000 个神经元的隐藏层就有约 1.5 亿个权重，计算、显存开销大，也极易过拟合。
- **丢失空间结构**：展平后"相邻像素"的关系没了，同一个模式出现在不同位置时，要在不同位置分别学一遍。

卷积层对应的解法：

- 局部连接：每个输出只依赖输入的一小块局部区域。图像的边缘、纹理本来就由邻近像素决定，所以不需要全连接。这解决**参数量和计算量**问题。
- 平移等变性（靠参数共享实现）：同一个卷积核滑过整张图，同一种特征在任何位置都用同一组参数检测。这进一步**减少参数**，并且物体平移，特征图也跟着平移。

注意是"等变"，不是"不变"。真正的局部平移不变性主要来自池化。

## 2. 卷积核如何滑动？"卷积"与数学卷积有何区别？

核按**步幅 $s$** 在输入上滑动。每到一个位置，就把核与对应窗口逐元素相乘再求和，加上偏置，得到输出的一个值。所有位置的结果组成特征图：

$$y_{i,j}=\sum_{m,n} w_{m,n},x_{is+m,;js+n}+b$$

区别：数学卷积要把**核翻转 180°** 再滑动，而深度学习里的"卷积"实际是互相关，不翻转。核是学出来的，翻不翻转只是参数排列不同，表达能力等价，所以省掉这一步。

## 3. 输入 32×32，核 5×5，填充 2，步幅 2，输出尺寸？

$$O=\left\lfloor\frac{W-K+2P}{S}\right\rfloor+1=\left\lfloor\frac{32-5+4}{2}\right\rfloor+1=15+1=16$$

输出是 16×16。

这个公式就是一道"数窗口能放几个"的题。只看一个方向（宽或高），两个方向各算一次。

### 推导

**第一步：填充让输入变长。**  
左右各补 $P$ 个像素，所以**实际参与滑动的长度**是

$$W' = W + 2P$$

**第二步：给窗口编号。**  
把像素位置记为 $0,1,\dots,W'-1$。核的宽度是 $K$，第 $n$ 个窗口的左边缘在 $nS$（$n=0,1,2,\dots$），它覆盖的位置是 $nS,\ nS+1,\dots,\ nS+K-1$。

**第三步：窗口不能伸出输入。**  
最右边的像素是 $W'-1$，所以要求

$$nS + K - 1 \le W' - 1 ;\Longrightarrow; nS + K \le W' ;\Longrightarrow; n \le \frac{W'-K}{S}$$

**第四步：数个数。**  
$n$ 必须是整数，所以最大的 $n$ 是 $\left\lfloor\frac{W'-K}{S}\right\rfloor$。又因为 $n$ 从 0 开始，窗口个数要再加 **1**（栽树问题：n 次挪动对应 n+1 个位置）：

$$O = \left\lfloor\frac{W'-K}{S}\right\rfloor + 1 = \left\lfloor\frac{W-K+2P}{S}\right\rfloor + 1$$

## 4. 输入 3 通道、输出 16 通道、核 5×5，参数量？为何与图像尺寸无关？

- 权重：$16\times3\times5\times5=1200$
- 偏置：16
- 总计：1216 个

参数只取决于**核大小和输入输出通道数**。因为同一个核共享地滑过所有位置，输入的 $H\times W$ 变大，只会增加计算量（FLOPs），不会增加参数。

## 5. 多输入多输出通道怎么算？1×1 卷积为何能融合通道信息？

![[Pasted image 20261102163229.png|686]]
设输入有 2 个通道，核是 2×2，只看一个窗口位置：
- 通道 1 窗口 $\begin{bmatrix}1&2\\3&4\end{bmatrix}$，核第 1 层 $\begin{bmatrix}1&0\\0&1\end{bmatrix}$，得 $1\times1+2\times0+3\times0+4\times1=5$
- 通道 2 窗口 $\begin{bmatrix}1&1\\0&2\end{bmatrix}$，核第 2 层 $\begin{bmatrix}2&0\\0&2\end{bmatrix}$，得 $1\times2+1\times0+0\times0+2\times2=6$
- 合计 $5+6=11$（再加偏置），这就是输出上的 1 个数。


每个输出通道对应一个形状为 $C_{in}\times K\times K$ 的核。计算时先把每个输入通道分别和核的对应切片做二维互相关，再把 $C_{in}$ 个结果逐位置相加，加偏置，得到一个输出通道。$C_{out}$ 个核就得到 $C_{out}$ 个输出通道：

$$y_{o,i,j}=\sum_{c}\sum_{m,n}w_{o,c,m,n},x_{c,i+m,j+n}+b_o$$

1×1 卷积不看空间邻域，只在每个像素位置上对通道向量做一次线性组合，相当于逐像素共享的全连接层。每个输出通道都是所有输入通道的可学习加权和，所以能融合通道信息。它常用来：

- 升降维：如 Inception 和 ResNet bottleneck 里先降维再做 3×3
- 增加非线性：后面接激活函数
- 节省参数：参数量只有 $C_{in}C_{out}$

## 6. 最大池化与平均池化的区别？为何降尺寸？一定提升效果吗？

- 最大池化取窗口**最大值**，保留最强响应，对边缘、纹理这类显著特征友好，也带来小范围的平移不变性。
- 平均池化**取窗口均值**，保留整体信息、更平滑，但会稀释强特征。
- 降尺寸：窗口内多个值汇聚成一个，步幅大于 1 时输出变小，例如 2×2、步幅 2 时长宽减半。**池化层没有可学习参数**。
- 不一定提升效果：池化会丢失位置和细节信息，对分割、检测等需要精确定位的任务不利。所以现代网络**常用步幅为 2 的卷积代替池化**，最后用全局平均池化代替全连接层。池化的好处是降低计算量、扩大感受野、增强对小位移的鲁棒性。

## 7. 什么是感受野？堆叠多个 3×3 与一个大核相比？

![[Pasted image 20261102163821.png|926]]
![[Pasted image 20261102163838.png|926]]

**感受野**是输出特征图上某个位置对应到输入上的**区域大小**。步幅为 1 时，n 层 3×3 卷积的感受野是 $2n+1$：两层是 5×5，三层是 7×7。

三层 3×3 与一个 7×7（输入输出通道均为 $C$）对比：
- 参数：$27C^2$ 对 $49C^2$，少约 45%
- 非线性：多了两次激活，表达能力更强
- 缺点：层数多，中间特征图占更多显存，串行计算延迟更高，网络更深也更难优化

## 8. LeNet、AlexNet、VGG、GoogLeNet 各自的关键思想？

- LeNet（1998）：确立"**卷积、池化、全连接**"的基本范式，用局部连接、权值共享、下采样做手写数字识别。
- AlexNet（2012）：更深更大，引入 ReLU（缓解梯度消失、训练更快）、Dropout、数据增广、重叠最大池化，并用 GPU 训练，在 ImageNet 上大幅领先。
- VGG（2014）：全部用 3×3 小卷积反复堆叠，把网络加深到 16/19 层，**结构规整**，证明了深度的重要性。大部分参数在最后的全连接层。
- GoogLeNet（2014）：Inception 模块并行使用 1×1、3×3、5×5 和池化，提取多尺度特征。用 1×1 卷积降维控制计算量，用全局平均池化取代大全连接层，参数量只有 AlexNet 的十几分之一。

逐步提升的原因是几方面叠加：网络更深带来更强的层次化抽象，训练技巧（ReLU、Dropout 等）让深网络能训得动，结构更高效（小核、1×1、多尺度），再加上更大的数据和算力。

## 9. ResNet 残差块如何计算？为何缓解退化？形状不一致怎么连？

残差块计算：

$$y=\text{ReLU}\big(F(x)+x\big)$$

其中 $F$ 通常是"卷积、BN、ReLU、卷积、BN"。网络学的是残差 $F(x)=H(x)-x$，而不是直接学 $H(x)$。

退化问题指网络加深后，训练误差反而上升。这是优化困难，不是过拟合。残差连接缓解它的原因：

- 恒等映射更容易学：只要把 $F$ 推到 0，多出来的层就等价于恒等，深网络至少不比浅网络差。
- 梯度有直通路径：$\frac{\partial y}{\partial x}=\frac{\partial F}{\partial x}+1$，其中的 $1$ 保证梯度不会逐层衰减到零。

输入输出形状不一致（通道数或空间尺寸变了）时，有两种做法：

- 投影捷径：用 1×1 卷积（步幅与主路径一致）把 $x$ 变换成 $W_s x$，再相加，这是最常用的做法。
- 补零捷径：下采样用步幅，通道不足的部分补零，不引入额外参数。

## 10. 小数据集上降低 CNN 过拟合

- 数据增广：随机裁剪、翻转、旋转、颜色抖动，以及 Cutout、Mixup、CutMix 等。本质是扩充数据多样性，注入"这些变换不改变标签"的先验。要注意不能破坏语义，比如数字 6 和 9 就不能随便翻转。
- 权重衰减（L2）：在损失里加 $\frac{\lambda}{2}|w|^2$，限制权重幅度，让模型更平滑。
- Dropout：训练时以概率 $p$ 随机丢弃神经元，相当于训练大量子网络的集成，减少神经元之间的共适应，测试时关闭。卷积层里用得较少，更多用在全连接层，卷积里可用 DropBlock 这类变体。
- 批量归一化：按 batch 对每个通道做 $\hat x=\frac{x-\mu_B}{\sqrt{\sigma_B^2+\epsilon}}$，再做可学习的缩放平移。主要作用是稳定训练、允许更大学习率，batch 统计量的噪声带来轻微正则效果，但它不是专门防过拟合的手段，batch 很小时还会变差。
- 迁移学习：用 ImageNet 预训练权重初始化，数据极少时冻结前面层只训练分类头，数据稍多时用小学习率微调全部或后几层。底层的边缘、纹理特征是通用的，这通常是小数据集上收益最大的一招。
- 其他常用手段：早停、缩小模型、标签平滑。
# RNN

## 1. 序列数据与表格数据的区别？RNN 如何用隐藏状态保存历史？

|      | 表格数据                 | 序列数据              |
| ---- | -------------------- | ----------------- |
| 样本关系 | 样本之间、特征之间无顺序，近似独立同分布 | 元素有先后顺序，后面依赖前面    |
| 长度   | 特征数固定                | 长度可变              |
| 打乱顺序 | 不影响含义                | 含义改变（"狗咬人"≠"人咬狗"） |

RNN 在每个时间步维护一个隐藏状态 $h_t$，由**当前输入**和**上一步隐藏状态**共同决定：

$$h_t=\varphi(W_{xh}x_t+W_{hh}h_{t-1}+b_h)$$

$h_t$ 相当于对 $x_1,\dots,x_t$ 的一份有损压缩摘要，历史信息就沿着 $h_{t-1}\to h_t$ 传下去。所有时间步共享同一套参数，所以能处理任意长度的序列，**参数量也不随长度增长**。

## 2. 基本 RNN 的公式与参数矩阵形状

设批量大小 $n$，输入维度 $d$，隐藏单元数 $h$，输出维度 $q$（采用行向量约定）：

$$H_t=\varphi(X_tW_{xh}+H_{t-1}W_{hh}+b_h),\qquad O_t=H_tW_{hq}+b_q$$

|符号|形状|
|---|---|
|$X_t$|$n\times d$|
|$H_t,,H_{t-1}$|$n\times h$|
|$W_{xh}$|$d\times h$|
|$W_{hh}$|$h\times h$|
|$b_h$|$1\times h$|
|$W_{hq}$|$h\times q$|
|$b_q,\ O_t$|$1\times q,\ n\times q$|

$\varphi$ 通常取 tanh。$H_0$ 一般初始化为 0。总参数量 $dh+h^2+h+hq+q$，与序列长度无关。

## 3. 什么是通过时间反向传播？为何序列越长越容易梯度消失或爆炸？

BPTT 就是把 RNN 沿时间展开成一个很深的网络（每层共享参数），在展开图上做反向传播。共享参数的梯度是各时间步梯度之和。

为方便书写用**列向量形式**（与上题差一次转置，结论不变）：$h_k=\varphi(W_{hh}h_{k-1}+W_{xh}x_k+b)$。损失对较早时间步 $t$ 的隐藏状态的梯度是：

$$\frac{\partial L_T}{\partial h_t}=\frac{\partial L_T}{\partial h_T}\prod_{k=t+1}^{T}\frac{\partial h_k}{\partial h_{k-1}},\qquad \frac{\partial h_k}{\partial h_{k-1}}=\text{diag}\big(\varphi'(a_k)\big),W_{hh}$$

这是 $T-t$ 个**雅可比矩阵的连乘**，范数大致按 $(\gamma)^{T-t}$ 变化，$\gamma$ 约为 $W_{hh}$ 的最大奇异值乘以激活函数导数：

- $\gamma<1$：梯度指数衰减，消失，学不到远处的依赖（tanh 的导数 $\le1$ 会加剧这一点）
- $\gamma>1$：梯度指数增长，爆炸，训练发散

序列越长，连乘的项越多，指数效应越明显。

## 4. 梯度裁剪如何缓解爆炸？为何不能解决消失？

按范数裁剪：设阈值 $\theta$，对全部参数梯度拼成的向量 $g$ 做

$$g\leftarrow\min!\Big(1,\frac{\theta}{|g|}\Big),g$$

梯度范数超过 $\theta$ 时等比缩放到 $\theta$，方向不变，只限制单步更新幅度，避免参数被一次更新冲飞、出现 NaN。（也有按值裁剪，对每个元素限幅。）

它不能解决消失：裁剪只会把过大的梯度压小，不会把过小的梯度放大。梯度已经接近 0 时，远处的信息在反传中早已丢失，裁剪无能为力。消失问题要靠结构改动：LSTM/GRU 的门控、残差或跳连、合适的初始化（如正交初始化）、注意力（缩短依赖路径）等。

## 5. 语言模型的目标？如何构造训练样本？困惑度为何能评价语言模型？

目标：估计一段文本的概率，用链式法则分解成"预测下一个词元"：

$$P(x_1,\dots,x_T)=\prod_{t=1}^{T}P(x_t\mid x_1,\dots,x_{t-1})$$

构造样本：标签就是输入向后平移一位。取长度为 $\tau$ 的子序列，输入 $X=(x_i,\dots,x_{i+\tau-1})$，标签 $Y=(x_{i+1},\dots,x_{i+\tau})$，每个位置的标签都是它的下一个词元。

困惑度：

$$\text{PPL}=\exp!\Big(-\frac1n\sum_{t=1}^{n}\log P(x_t\mid x_{<t})\Big)$$

即平均交叉熵取指数。直观含义是模型预测下一个词时，平均相当于在多少个等可能的候选中犹豫：

- 最好是 1（每次都预测对）
- 随机均匀猜测时等于词表大小 $|V|$
- 越小越好

它按词元数做了平均，所以不同长度的文本可以比较。注意词表或分词方式不同的模型，困惑度不能直接对比。

## 6. 随机采样与顺序分区有何区别？隐藏状态如何处理？

|       | 随机采样<br>                    | 顺序分区                                           |
| ----- | --------------------------- | ---------------------------------------------- |
| 构造方式  | 从原序列随机起点取子序列                | 按顺序切分，相邻批次中同一行的子序列在原序列中首尾相接                    |
| 相邻小批量 | 在原序列里不连续                    | 连续                                             |
| 隐藏状态  | 每个小批量开始前重新初始化（上一批的末状态与这批无关） | 可以把上一批的末状态作为下一批的初始状态，但要 `detach`，切断梯度（截断 BPTT） |
| 特点    | 更接近独立同分布，但丢失跨批上下文           | 保留长程上下文，但相邻批次相关性强                              |

## 7. GRU 的重置门和更新门？何时接近普通 RNN？

$$R_t=\sigma(X_tW_{xr}+H_{t-1}W_{hr}+b_r),\qquad Z_t=\sigma(X_tW_{xz}+H_{t-1}W_{hz}+b_z)$$

$$\tilde H_t=\tanh!\big(X_tW_{xh}+(R_t\odot H_{t-1})W_{hh}+b_h\big),\qquad H_t=Z_t\odot H_{t-1}+(1-Z_t)\odot\tilde H_t$$

- 重置门 $R_t$：决定计算候选状态时用多少历史。$R_t\to0$ 时相当于忽略过去、重新开始，擅长捕获短期依赖。
- 更新门 $Z_t$：决定新旧状态如何混合。$Z_t\to1$ 时直接拷贝旧状态，输入被跳过，信息长期保留，擅长长期依赖。

当 $R_t\approx1$（完全使用历史）且 $Z_t\approx0$（完全用候选状态覆盖）时，$H_t=\tanh(X_tW_{xh}+H_{t-1}W_{hh}+b_h)$，就退化成普通 RNN。（有的教材 $Z_t$ 的方向相反，注意区分。）

## 8. LSTM 三个门的作用？记忆单元为何有助于长期依赖？

$$C_t=F_t\odot C_{t-1}+I_t\odot\tilde C_t,\qquad H_t=O_t\odot\tanh(C_t)$$

- 输入门 $I_t$：控制候选信息 $\tilde C_t$ 有多少写入记忆单元
- 遗忘门 $F_t$：控制上一时刻记忆 $C_{t-1}$ 保留多少
- 输出门 $O_t$：控制记忆单元有多少暴露到隐藏状态 $H_t$，用于输出和下一步

为何有助于长期依赖：记忆单元的更新是逐元素加法，主要的梯度路径是

$$\frac{\partial C_t}{\partial C_{t-1}}\approx F_t$$

它不像普通 RNN 那样每步都乘一次权重矩阵再过 tanh。当 $F_t\approx1$ 时，梯度几乎无衰减地沿记忆单元传下去，类似残差连接里的"恒等通道"。门是由内容学出来的，模型可以自己决定何时记住、何时清除。实践中常把遗忘门偏置初始化为 1，让一开始就倾向于保留记忆。

## 9. 双向、深层与单向 RNN 的区别？为何双向不适合自回归生成？

|     | 结构                                                                      | 适用场景                                |
| --- | ----------------------------------------------------------------------- | ----------------------------------- |
| 单向  | 只用过去：$h_t=f(x_t,h_{t-1})$                                               | 语言建模、自回归生成、在线或流式预测                  |
| 深层  | 多层堆叠，第 $l$ 层的输入是第 $l-1$ 层的隐藏状态序列                                        | 需要更强层次化表示的任务，通常 2～4 层，层数多了要配残差或层归一化 |
| 双向  | 两个方向的 RNN 各算一遍，每步拼接 $[\overrightarrow{h_t};\overleftarrow{h_t}]$，输出维度翻倍 | 整句已知时的理解任务：命名实体识别、词性标注、文本分类、翻译的编码器  |

双向 RNN 不适合自回归生成，原因有三：

- 生成时未来词元还没产生，后向状态根本算不出来。
- 训练时如果用了后向状态，等于模型提前看到了要预测的词，信息泄漏，训练和推理不一致。
- 语言模型的目标是 $P(x_t\mid x_{<t})$，本来就不该依赖 $x_{>t}$。

## 10. 教师强制、贪心搜索与束搜索？束宽越大为何不一定越好？

教师强制（训练时）：解码器每一步的输入用真实的上一个目标词元，而不是模型自己上一步的预测。收敛快、稳定、可并行；缺点是曝光偏差：训练时只见过正确前缀，推理时却要面对自己生成的、可能有错的前缀，误差会累积。

两种推理时的搜索：

- 贪心搜索：每步取概率最大的词，速度快，但只是局部最优，可能错过整句概率更高的序列。
- 束搜索：每步保留累计 log 概率最高的 $k$ 条候选，最后取得分最高的一条。$k=1$ 就是贪心。常对得分做长度归一化：$\frac1{L^\alpha}\sum\log p$。

束宽增大不一定更好：

- 搜索更充分，只是更接近模型自己的"最大概率序列"。模型概率最高不等于质量最好，反而容易得到过短、空洞、重复的"安全"输出。
- 长度偏置：连乘概率天然偏爱短句，不做长度归一化时，束越大越明显。
- 开放式生成（对话、写故事）中多样性下降。
- 计算量随束宽线性增长，收益却递减。翻译里束宽常取 4～10，过大 BLEU 反而可能下降。

这和你之前整理的采样笔记是同一个结论：翻译、摘要这类有较标准答案的任务适合束搜索，开放式生成适合 Top-P 加温度。

# Transformer 十题参考答案

## 1. 注意力要解决 RNN 的哪些局限？Query、Key、Value 分别表示什么？

RNN 的三个局限：

- **长距离依赖难**：信息要沿隐藏状态一步步传，两个位置之间的路径长度是 $O(n)$，还伴随梯度消失或爆炸。
- **无法并行**：$h_t$ 依赖 $h_{t-1}$，序列方向只能串行。
- **固定长度瓶颈**：传统 seq2seq 把整个源句压成一个固定向量，句子一长就丢信息。

注意力让任一位置直接访问所有位置，路径长度 $O(1)$，并按相关性动态加权。

三者的含义可以类比检索：

- Query：当前位置发出的"我想找什么"
- Key：每个位置带的"标签"，用来和 Query 匹配
- Value：每个位置实际携带的内容

Query 和 Key 的匹配程度经 softmax 变成权重，再对 Value 加权求和。Q·K 决定"看谁"，V 决定"取什么"。

## 2. 缩放点积注意力公式，为什么要除以 $\sqrt{d_k}$？

$$\text{Attention}(Q,K,V)=\text{softmax}\Big(\frac{QK^\top}{\sqrt{d_k}}\Big)V$$

形状：$Q\in\mathbb R^{n\times d_k}$，$K\in\mathbb R^{m\times d_k}$，$V\in\mathbb R^{m\times d_v}$，输出 $n\times d_v$。掩码（如果有）加在 softmax 之前。

除以 $\sqrt{d_k}$ 的原因：设 $q,k$ 的各分量独立、均值 0、方差 1，则点积 $q\cdot k=\sum_{i=1}^{d_k}q_ik_i$ 的均值为 0，方差为 $d_k$，标准差 $\sqrt{d_k}$。$d_k$ 一大（比如 64，标准差就是 8），点积的幅度很大，softmax 会进入饱和区，输出接近 one-hot，而 softmax 的梯度正比于 $p(1-p)$，几乎为 0，训练困难。除以 $\sqrt{d_k}$ 把**方差拉回 1，保持 softmax 输入的尺度稳定**。

## 3. 加性注意力与缩放点积注意力有什么区别？

|      | 加性注意力                                                       | 缩放点积注意力                            |
| ---- | ----------------------------------------------------------- | ---------------------------------- |
| 打分函数 | $w_v^\top\tanh(W_qq+W_kk)$                                  | $q^\top k/\sqrt{d_k}$              |
| 参数   | 有（$W_q,W_k,w_v$）                                            | 无                                  |
| 维度要求 | $q$、$k$ 维度可不同                                               | 需要同维度                              |
| 计算   | 每一对 $(q,k)$ 都过一次小前馈网络，需要 $n\times m\times h$ 的中间张量，$O(nmh)$ | 一次矩阵乘 $QK^\top$，$O(nmd)$，GPU 上高度优化 |

适用场景：

- $q$、$k$ 维度不一致，或需要更灵活的对齐函数时，用加性注意力（早期 seq2seq 注意力用的就是它）。
- Transformer 和大模型用缩放点积，同样的理论复杂度下速度和显存都更好。
- 原论文指出：$d_k$ 小时两者效果接近，$d_k$ 大时不缩放的点积不如加性，缩放之后弥补了这一差距。

## 4. 自注意力与编码器-解码器注意力有什么区别？QKV 各来自哪里？

- 自注意力：Q、K、V 都来自同一个序列，即同一层的输入 $X$，分别经 $W_Q,W_K,W_V$ 线性投影得到。用来建模序列内部各位置之间的关系。
- 编码器-解码器注意力（交叉注意力）：Q 来自解码器（上一子层的输出），K、V 来自编码器的最终输出。用来让目标端的每个位置去"对齐"源序列。

Transformer 里一共三处注意力：编码器的自注意力（双向）、解码器的掩蔽自注意力（只看过去）、解码器的交叉注意力。

## 5. 多头注意力如何计算？为什么多头可能比单头更丰富？

$$\text{head}_i=\text{Attention}(QW_i^Q,,KW_i^K,,VW_i^V),\qquad \text{MultiHead}=\text{Concat}(\text{head}_1,\dots,\text{head}_h),W^O$$

通常取 $d_k=d_v=d_{model}/h$（例如 $512/8=64$），所以总计算量和一个全维度的单头差不多。

为什么更丰富：单头对每个位置只产生一组注意力权重，是一次加权平均，会把不同类型的关系"平均掉"。多头让模型在不同的投影子空间里**并行学习不同的关系**（比如邻近关系、句法依存、指代、语义相似），每个头可以关注不同的位置，最后拼接融合。

不过实验也发现部分头是冗余的，可以剪掉而几乎不影响效果，所以"多头更好"是容量和灵活性上的优势，不是每个头都有意义。

## 6. 为什么需要位置编码？正弦余弦位置编码如何表示位置和相对距离？

为什么需要：自注意力对输入顺序是置换等变的，把词序打乱，每个词的输出只是跟着换位，注意力分数不变。没有位置信息，"狗咬人"和"人咬狗"对模型来说词集一样。RNN 靠顺序递推隐含了位置，而 Transformer 并行处理所有位置，必须显式注入。

正弦余弦编码：

$$PE_{(pos,2i)}=\sin\Big(\frac{pos}{10000^{2i/d}}\Big),\qquad PE_{(pos,2i+1)}=\cos\Big(\frac{pos}{10000^{2i/d}}\Big)$$

它与词嵌入相加。每一对维度 $(2i,2i+1)$ 是一个频率 $\omega_i=10000^{-2i/d}$ 的正余弦，频率从高到低排列，像不同位数的计数器：**低维变化快，区分相近位置；高维变化慢，区分远处位置**。

表示相对距离：由和角公式

$$\begin{bmatrix}\sin\omega(p+k) \\ \cos\omega(p+k)\end{bmatrix} = \begin{bmatrix}\cos\omega k & \sin\omega k \\ -\sin\omega k & \cos\omega k\end{bmatrix}\begin{bmatrix}\sin\omega p \\ \cos\omega p\end{bmatrix}$$

即 $PE_{p+k}$ 是 $PE_p$ 的一个线性变换（旋转），而且这个变换只取决于**偏移量 $k$**，与绝对位置 $p$ 无关。此外 $PE_p\cdot PE_{p+k}=\sum_i\cos(\omega_ik)$ 也只依赖 $k$。所以模型容易学到"相对距离"。

其他方案还有**可学习的位置嵌入**、RoPE、ALiBi 等。

## 7. 编码器层由哪些模块组成？残差、层归一化、逐位置前馈网络各有什么作用？

一层 = 多头自注意力 → Add & Norm → 逐位置 FFN → Add & Norm。

- **残差连接** $y=x+\text{Sublayer}(x)$：梯度有直通路径（$\partial y/\partial x=I+\dots$），**缓解深层网络的退化和梯度消失**，子层只需要学"增量"，所以能堆很多层。
- **层归一化**：对每个 token 在特征维度上归一化（减均值、除标准差，再乘可学习的缩放加平移），**稳定激活分布、加速收敛**。它不依赖 batch，适合变长序列和小 batch（这点和 BatchNorm 不同）。原论文是先加后归一化（Post-LN），后来的深层模型多用 Pre-LN，训练更稳。
- **逐位置前馈网络**：$\text{FFN}(x)=\max(0,xW_1+b_1)W_2+b_2$，维度 $d_{model}\to d_{ff}\ (\text{常取}\ 4d_{model})\to d_{model}$，对每个位置独立、共享参数。注意力本质上是对 Value 的加权平均（线性混合），FFN 提供非线性和逐位置的特征加工，它的参数量也占大头。

分工：注意力**负责位置之间交换信息**，FFN **负责每个位置内部的特征变换**。

## 8. 解码器为什么要掩蔽自注意力？去掉因果掩码会出什么问题？

解码器是自回归的，目标是 $P(y_t\mid y_{<t},x)$。训练时用教师强制，整条目标序列一次性并行输入。如果不加掩码，位置 $t$ 的自注意力就能看到 $t+1,t+2,\dots$ 的真实词，等于偷看答案。

因果掩码的做法：在 softmax 之前，把 $j>t$ 的分数设为 $-\infty$（**上三角掩码**），这些位置的权重就变成 0。

去掉掩码的后果：

- 训练时：模型可以直接从输入里抄出下一个词，损失会很低，但学到的是复制，而不是预测。
- 推理时：生成是一个词一个词来的，未来词根本不存在。模型习惯了看到未来，现在看不到了，训练和推理的分布不一致，**生成质量会崩溃**，输出基本是乱的。

另外还有 padding 掩码，用来**屏蔽填充位置**，和因果掩码是两回事，两者常要叠加。

## 9. 自注意力的时间和空间复杂度？与 RNN 相比，并行训练和长序列建模各有什么优缺点？

设序列长度 $n$，隐藏维度 $d$：

|            | 自注意力                     | RNN       |
| ---------- | ------------------------ | --------- |
| 每层计算量      | $O(n^2d)$                | $O(nd^2)$ |
| 序列方向的串行步数  | $O(1)$                   | $O(n)$    |
| 任意两位置的路径长度 | $O(1)$                   | $O(n)$    |
| 空间（激活）     | $O(n^2)$（注意力矩阵）加 $O(nd)$ | $O(nd)$   |

（自注意力的投影部分还有 $O(nd^2)$。）

- **并行训练**：Transformer 完胜。整条序列的所有位置同时算，GPU 利用率高；RNN 训练必须按时间步串行。
- 长序列建模：Transformer 的长距离依赖是一步直达，不会因为距离衰减，但代价是 $n^2$ 的时间和显存，序列一长就爆炸，需要 **FlashAttention**（减少显存和访存，不改变 $O(n^2)$ 的计算量）、**稀疏或滑动窗口注意力**、**线性注意力**等改进。RNN 推理时每步是常数时间和常数大小的状态，适合流式场景，但长依赖弱、训练串行。
- 其他差别：Transformer 的位置信息要**显式注入**；当 $n<d$ 时，自注意力反而比 RNN 每层更便宜。

## 10. 训练损失正常下降，但推理输出大量重复词元，可能是什么原因？

建议按下面的顺序排查，每一类都配一个典型原因：

- **解码策略**（最常见）：贪心或束搜索在最大化概率，一旦出现重复，重复内容的条件概率会更高，自我强化，形成循环；束宽越大越明显。没有重复惩罚、`no_repeat_ngram`，温度太低，Top-K/Top-P 设得不合适，都会加重。
- 掩码：
    - 训练时因果掩码缺失或写错，损失会因为泄漏而"正常下降"，推理一用就崩。
    - padding 掩码缺失，填充位置参与注意力或损失。
    - 增量解码（KV cache）时，掩码或缓存实现与训练不一致。
- 位置编码：
    - 推理长度超过训练的最大长度，位置编码没见过，注意力塌缩，常出现重复。
    - 增量解码时位置索引没有递增，每一步都按位置 0 处理，模型"以为"一直在开头，输出会反复。
- **数据处理**：
    - 训练数据本身重复多，没有去重。
    - 起止符处理有误：**EOS** 没加、被截断，或被 pad 掩码一起忽略，模型学不会停止，只能一直生成。
    - 输入和标签的错位（shift）写错，训练与推理的分词、特殊符号处理不一致。
- 训练目标：
    - 只用教师强制加交叉熵，存在曝光偏差，推理中一旦出现错误前缀就难以恢复。
    - 损失没有忽略 pad，被大量填充位置稀释，数值上"下降得很好看"。
    - 教师强制下的损失或困惑度，并不能反映自由生成的质量。

排查顺序：先换解码方式（采样，加重复惩罚）看是否缓解；再拿一条训练样本，对比"教师强制一次性前向"和"自回归逐步前向"的 logits 是否一致，这一步能直接暴露掩码、缓存、位置编码的 bug；最后检查数据的重复和 EOS 处理，以及推理长度有没有超过训练长度。
