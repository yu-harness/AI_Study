# 2.6.3 FlashAttention 伪代码

FlashAttention 的核心是把**注意力计算**拆成能塞进 SRAM 的小块，边算边累加，全程不生成 $N\times N$ 的分数矩阵。

## 一、输入与输出

| 项 | 形状 | 位置 |
| --- | --- | --- |
| 输入 $Q,K,V$ | $N\times d$ | HBM |
| 片上 SRAM 容量 | $M$ | — |
| 输出 $O$ | $N\times d$ | HBM |
| 每行累加量 $m,\ell$ | 各 $N$ 维 | HBM |

$m_i$ 记第 $i$ 行目前遇到的最大值，$\ell_i$ 记该行按 $e^{x-m}$ 累积的指数和。

## 二、算法整体结构

$$
\text{切块} \rightarrow \text{外层遍历 }K,V \rightarrow \text{内层遍历 }Q \rightarrow \text{更新 }O_i,\ m_i,\ \ell_i
$$

```text
for j = 1..Tc:                    # 外层：K/V 块，只读一遍
    载入 K_j, V_j 到 SRAM
    for i = 1..Tr:                # 内层：Q 块
        载入 Q_i, O_i, ℓ_i, m_i 到 SRAM
        S_ij = Q_i · K_jᵀ         # 只算 Br×Bc
        块内 rowmax / exp / rowsum
        合并到全局 m_i, ℓ_i
        更新 O_i 并写回
```

## 三、逐行拆解

| 行 | 原始操作 | 在做什么 |
| --- | --- | --- |
| 1 | $B_c=\lceil M/4d\rceil$，$B_r=\min(\lceil M/4d\rceil,d)$ | 定块大小：一行块要同时容纳 q、k、v、o 四组 $d$ 维向量，故上限为 $M/4d$ 行 |
| 2 | $O=0$，$\ell=0$，$m=-\infty$ | 初始化累加量；$m$ 取负无穷便于第一次比较被替换 |
| 3–4 | $Q$ 切 $T_r$ 块（$B_r\times d$），$K,V$ 切 $T_c$ 块（$B_c\times d$），$O,\ell,m$ 随 $Q$ 切 $T_r$ 份 | 分块 |
| 5–6 | 载入 $K_j,V_j$ | 外层按 K/V 走，它们服务所有 Q 块，只读一遍 |
| 7–8 | 载入 $Q_i,O_i,\ell_i,m_i$ | 内层按 Q 走，把上一轮的状态取回来继续累加 |
| 9 | $\mathbf{S}_{ij}=\mathbf{Q}_i\mathbf{K}_j^{\top}\in\mathbb{R}^{B_r\times B_c}$ | 只算一个小块分数 |
| 10 | $\tilde m_{ij}=\operatorname{rowmax}(\mathbf{S}_{ij})$，$\tilde{\mathbf{P}}_{ij}=\exp(\mathbf{S}_{ij}-\tilde m_{ij})$，$\tilde\ell_{ij}=\operatorname{rowsum}(\tilde{\mathbf{P}}_{ij})$ | 块内局部 softmax 的三件套 |
| 11 | $m_i^{\text{new}}=\max(m_i,\tilde m_{ij})$，$\ell_i^{\text{new}}=e^{m_i-m_i^{\text{new}}}\ell_i+e^{\tilde m_{ij}-m_i^{\text{new}}}\tilde\ell_{ij}$ | 更新全局最大值与总和，旧值按新基准缩放 |
| 12 | $\mathbf{O}_i\leftarrow\operatorname{diag}(\ell_i^{\text{new}})^{-1}\big(\operatorname{diag}(\ell_i)e^{m_i-m_i^{\text{new}}}\mathbf{O}_i+e^{\tilde m_{ij}-m_i^{\text{new}}}\tilde{\mathbf{P}}_{ij}\mathbf{V}_j\big)$ | 旧输出缩放到新基准，加上本块贡献，再整体归一化 |
| 13 | $\ell_i\leftarrow\ell_i^{\text{new}}$，$m_i\leftarrow m_i^{\text{new}}$ | 存回状态，供下一块使用 |
| 16 | 返回 $O$ | 输出最终注意力结果 |

第 12 行的括号有两项：**旧结果的缩放**与**本块的新贡献**，最后统一除以 $\ell_i^{\text{new}}$。

## 四、三个关键设计

**小块计算**：$\mathbf{S}_{ij}$ 只有 $B_r\times B_c$，算完即弃。整行整列的 $N\times N$ 矩阵从未出现，显存由 $O(N^2)$ 降到 $O(N)$。

**缩放合并**：不同块算出的 $\tilde m$、$\tilde\ell$ 基准不同，靠 $e^{m_i-m_i^{\text{new}}}$ 一项把所有旧结果搬到新基准上，数学上与整行一次算完完全等价。

**循环顺序**：外层 K/V、内层 Q。K/V 每块只搬一次却服务全部 Q 块；Q、O 在内层反复更新。顺序反过来会让 K/V 重复搬运多次。

## 五、走一个具体例子

设 $N=2048$、$d=128$，取 $B_r=B_c=128$。

| 量 | 值 |
| --- | --- |
| 分数矩阵规模 | $2048\times2048=419$ 万个元素 |
| 分块后 | $16\times16=256$ 块，每块 $128\times128$ |
| 单次搬入量 | Q 的第 3 块 + K/V 的第 5 块，约为全量的 $1/256$ |
| 峰值中间量 | 只有一块 $\mathbf{S}_{ij}$ 与 $B_r$ 维的 $\tilde m,\tilde\ell$ |

## 六、小结

**切块 → 块内局部 softmax → 用缩放把结果并进全局累加量 → 丢弃中间结果。** 只要 $m_i$、$\ell_i$ 维护正确，分块计算与整行计算的结果完全相同，这正是它能在有限 SRAM 上跑长序列的原因。
